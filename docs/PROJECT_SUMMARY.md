## 1. 研究什么

同一张图受到多种退化时，单项测试不能完整描述它会怎样出错。本项目先诊断这类错误，再检验组合覆盖训练，最终探索从无标签目标域图像估计退化场、构造复合增强的 NCF 方法。

**研究主角是 NCF；诊断与配对覆盖是方法的动机和设计依据。** NCF 有 CIFAR 上的初步正结果，但海事主任务对照是否定的（四 seed 下未超过具名配方臂），失败可追溯到估计器对 cloud/glare 的无能为力。因此当前证据支持“诊断 + 配对覆盖”，不支持“NCF 是更好的海事鲁棒方法”。

## 3. 当前方法结果怎样读

以下为 seed17、同一 CIFAR stem ResNet-18 的 601 条件探索结果。601 是 CIFAR 的网格规模，不是海事协议的条件数。

| 方法／信息条件 | Clean % | 单项 % | 复合 % |
|---|---:|---:|---:|
| Standard／无目标域信息 | 95.47 | 74.77 | 57.29 |
| AugMix／通用增强 | 95.36 | 88.95 | 78.72 |
| Single-family／已知测试退化族 | 94.99 | 92.30 | 86.77 |
| Pair Coverage k=15／已知退化配方参考 | 94.28 | 91.80 | 87.88 |
| NCF／含核双场、全族目标池 | 95.05 | 90.76 | 84.66 |
| NCF／含核双场、场库池排除雾霜雪 | 94.55 | 90.88 | 85.43 |

这些数值使用代码生成的 CIFAR-10-C 风格退化及其顺序复合，不作为 AugMix 官方复现成绩。全族 NCF 与 k=15 的复合差距为 **3.22 pp**；排除三族的场库臂差距为 **2.45 pp**。这两个数不能互换，也不能直接套到留出族子集。

**F2 已有完整 seed17 结果：**同含核场库、每场重复 m=2，单场复合测试准确率 **82.57%**，双场 **84.66%**，差 **+2.09 pp**。这是复合采样的初步支持，仍需区分双场总损伤变强的作用。第二 seed 是否已完成以 [动态台账](../reports/RESEARCH_RESULTS.md) 为准，不引用部分网格均值。

**海事主表（FGSC-23 / ConvNeXt-T，四 seed，157 图开发集）**：standard 63.27、AugMix 65.29、strong_combo 75.12、pair_coverage 74.21、NCF 70.96（天气复合准确率，百分点）。NCF 的收益随严重度增长（相对 standard 由 sev1 的 −1.1 升到 sev5 的 +16.0），但从未追平具名配方臂。只读诊断给出原因：估计器把 cloud 判成近似恒等变换（重构 PSNR 比实际损伤高 10–14 dB），glare 只在严重度 ≥3 部分生效，haze 被完全解释；这与“含 haze 的组合收益最大、cloud+glare 最小”完全一致。因此这次失败发生在复合采样之前，不在采样环节。

## 4. 当前不能跨过的结论边界

- **两个交互量回答不同问题。** 加性交互与错误并集残差可以异号；错误并集残差是“新增错误减恢复旧错误”，不等于新增错误本身。
- **严重度结论依赖实现。** 已测高严重度的损失更突出；另一渲染器从严重度 4 就出现额外交互，不能宣称统一的物理阈值。原单调性预测仅 2/6 运行满足。
- **跨骨干诊断不等于方法跨骨干有效。** 多骨干失效分析已经做过，NCF 的完整方法验证主要仍在 CIFAR / ResNet-18。
- **目标域感知不等于无目标信息泛化。** NCF 可访问目标图像池，AugMix 对照不使用该信息。场库留出族与训练留出配对分别报告。
- **真实数据仅为观察性证据。** FGSC-23 的 −2.3 pp、−7.8 至 +4.3 是均值与种子差值范围，后者不是置信区间。两库重度样本均仅 2 张，不能验证严重退化下的普遍表现。
- **历史负结果继续保留。** RGPA、复原、联合训练及多批候选筛选未通过原准入，不作为与 NCF 并列的贡献。

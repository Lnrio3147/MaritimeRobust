# 复合天气退化下的海事船舶识别：工作总结

2026-11-02。所有数字可由 `reports/` 下的报告与 `scripts/` 下的脚本复现，
`reports/snapshot.json` 记录了每次运行的代码与配置。

---

## 一句话

现有鲁棒性评测把天气退化当作彼此独立的单项来处理，而真实海况是复合并发；
本文用配对协议量化复合与单项的差距，把差距定位到"共现覆盖"这一可操作的点上，
并给出一个不需要族名、只用无标签部署图像就能逼近该覆盖的模块。

---

## 1. 问题

**评测层面的三个缺陷。**

1. **单项评测高估鲁棒性。** 合成数据的标准做法是逐族、逐严重度单独施测，取平均。
   但部署中雾、雨、运动模糊往往同时出现。单项均值无法回答"两种退化叠加会怎样"。
2. **加性假设没有被检验。** 复合条件下的精度被默认等于各单项精度之和（或损失之和）。
   在严重度 5，这个假设不成立（见 §3）。
3. **指标本身会给出反号结论。** 在 CIFAR-10-C 上，按加性约定衡量"复合超额"得到
   −7.8 pp（看似复合比单项更轻），按并集基线衡量得到 +3.6 pp。差距来自误差重叠
   被重复计数，同一个模型在同一批数据上得到相反的定性结论。

---

## 2. 做了什么（四块）

### 2.1 配对评测协议
15 个退化族两两配对成 105 对（剔除物理上不共存的组合），每对 5 个严重度，
共 525 个复合条件，与 75 个单项条件、clean 一起构成 601 条件的统一网格。
所有臂在完全相同的条件集合上评测，统计量为"复合精度 − 单项精度的加性预测"。
主实验数据为 FGSC-23 海事船舶分类（8 类），复现实验为 CIFAR-10-C。

### 2.2 误差并集分解
把复合错误按"是否来自任一单项失败"分解为三部分：两族各自的错误、以及
**只有复合才出现的错误（union-only）**。这把"更难"与"新失败模式"区分开。

### 2.3 覆盖率实验
在 6 个已标定的族上构造嵌套配对池（k=3/6/12/15 对），每次留出 3 对不参与训练，
度量模型在**未见过**的复合对上的超额。对照臂为：单项训练、等损伤匹配的单项训练、
AugMix、以及打乱配对配方。

结论：超额不是内在属性，是**训练分布没覆盖复合点**造成的操作点效应。
覆盖同一批族之后，留出对的超额从 +8.2 pp 降到 −1.8 pp，代价是干净精度 1.2 pp；
单项训练只降到 +7.2 pp——**配对本身就贡献了 5.8 pp**（6/6 折一致，区间 −8.4 .. −2.3）。

### 2.4 神经退化场模块（NCF）
部署时只有图像、没有族名清单。做法：把退化写成
`x_deg = k * (K ⊙ x_clean) + N + noise`
——逐图各向异性高斯核 k、8×8 粗增益 K、加性场 N、噪声尺度；
一个编码器从单张退化图回归全部参数，训练信号来自生成器自身的采样（连续先验，
不按族索引）。在无标签部署池上跑一遍得到场库；训练时采样 1–2 个场、在场空间复合、
按 PSNR 标定的次数施加到干净图上。**族名、干净参考、标签都不进入模块**。

## 3. 成果

### 3.1 主结果（CIFAR-10-C，601 条件，% 正确率）

| 臂 | clean | 单项 | 复合 | 含留出族的复合对 |
|---|---:|---:|---:|---:|
| clean 参考 | 95.47 | 74.77 | 57.29 | 58.99 |
| AugMix | 95.36 | 88.95 | 78.72 | 78.46 |
| 单项（真族名） | 94.99 | 92.30 | 86.77 | 86.84 |
| 配对 k=15（上界） | 94.28 | 91.80 | 87.88 | 87.64 |
| **场库，15 族全在池中** | 95.05 | 90.76 | **84.66** | 84.19 |
| **场库，雾/霜/雪不入池** | 94.55 | 90.88 | **85.43** | 84.96 |

- 覆盖率臂相对 clean 参考在 525 个复合条件下 **+30.60 pp**（95% CI [28.47, 32.69]），
  干净精度只掉 1.19 pp；AugMix +21.43 pp，差距 9.17 pp，**105 对中 104 对一致**。
- 场库（无族名）**+27.4 pp**，用留出族测试时仍有 84.96（AugMix 78.46，上界 87.64）。

### 3.2 超级可加性（海事 FGSC-23，配对协议）

- 严重度 5：复合精度比加性预测低 **11.3 pp**，且 41.5% 的复合错误在任一单项中都不出现
  （严重度 1→5 依次为 3.8 / 6.6 / 19.1 / 41.5%）。
- 严重度 ≤3：条件近似可加——超额是**阈值现象**，不是单调趋势。
- 该结论在四种骨干网络、两套渲染器下方向一致。

### 3.3 误差并集指标
加性约定在 CIFAR-10-C 上给出 −7.8 pp（反号），并集基线给出 +3.6 pp。
两者差距 = 误差重叠被重复计数的部分；指标的选择会改变论文结论的方向。

---

## 4. 解决了什么

1. **"复合有多坏"可量化、可复现**：601 条件统一网格 + 配对统计量，
   替代"单项平均值"这一默认做法。
2. **超额是操作点，不是数据属性**：覆盖实验证明它可被训练分布移除，
   并分离出"配对多样性"与"仅仅是见过这类退化"两个因素（5.8 pp 归配对本身）。
3. **部署时没有族名也能拿到大部分收益**：场库在完全无族名的条件下从 57.29 拿到 84.66，
   在族外测试下 85.43，说明退化可以写成连续场而非族标签。

## 5. 提升幅度（一句话版本）

| 对比 | 提升 |
|---|---|
| 覆盖训练 vs 干净参考 | **+30.6 pp** 复合精度（干净 −1.2 pp） |
| 覆盖训练 vs AugMix | **+9.2 pp**，104/105 对一致 |
| 场库（15 族全在池中） vs AugMix | **+5.9 pp** 复合精度 |
| 场库（雾/霜/雪不入池） vs AugMix | **+6.7 pp** 复合精度 |
| 含留出族的复合对：场库 vs AugMix | **+6.5 pp** |
| 场库 vs k=15 上界 | −2.45 pp（剩余差距） |
| 卷积核项 vs 无卷积核项 | 模糊类 +9~10 pp，噪声/光度类 <0.3 pp |

## 6. 负结果与边界（同等重要）

- **机制未知。** 七个机制差异明显的单点干预 + 一个初始化对照，全部打不过一个
  强组合增广基线；最好一个 +0.94 pp。可解释性统计是条件级关联（R²=0.80），
  逐图相关很弱（r=0.13/0.26）。
- **阈值只界定到 (4,5) 区间**，预注册的单调性预测失败（6 次运行中 2 次）。
- **真实数据只有观测证据**：157 张标注图，退化与干净组差 −2.3 pp [−7.8, +4.3]，不显著。
- **跨族不迁移**：池中没有的族（如 haze+glare）上覆盖无效——这是方法的边界，
  也是"必须覆盖预期会遇到的退化"这一部署要求的来源。
- **主实验单一数据集**、两个 seed；CIFAR 复现补上了跨数据集一环，但仍是合成数据。
- 场估计器受 8×8 网格容量限制，雾的透射率被高估（0.72 vs 真实约 0.2）。

# NCF: Neural Corruption Fields — 模块规格

*状态：设计稿（2026-11-01）。尚未实现，尚未有任何结果。下文所有"预期"都不是测量值。*

## 0. 为什么要这个模块（来自已有的测量，不是推测）

本项目的诊断结论（论文 §4.6、§4.7、§5）是：

1. 组合退化的误差**多于**其组成部分误差集合的并（`delta = e(a+b) − |E_a ∪ E_b| > 0`，海事实测 +11.3 pp，
   CIFAR-10-C 复现 +3.6 pp）；
2. 这个超额**不是**"更难"，而是训练没有访问过的联合工作点；覆盖对应族即可消除
   （CIFAR：57.3% → 87.9%，代价 1.2 pp 干净精度）；
3. 覆盖的收益与"配对"无关（B2 两个种子都失败），与**是否见过被测族**有关；
4. 族不相交时**不转移**（海事 P10：haze+glare 不改善）。

第 4 条是本文最硬的限制，也是模块要解决**唯一**的问题：
**在部署退化族未知时，如何自动覆盖它们。**

现有做法（AugMix、PixMix、DeepAugment、AutoAugment 一族）用固定算子集合增强，
与部署族没有对应关系；盲复原领域的退化估计（Probabilistic Degradation Estimator,
Neurocomputing 2024；QualNet, CVPR 2021）能估计**单一**退化的参数并重合成，
但它们不建模**组合**，而组合正是诊断指出的失效点。

## 1. 核心主张（一句话）

> 把退化表示为**连续的场**（空间增益 + 加性场），从无标签部署图像估计其分布，
> 再从**联合分布**采样并**复合**，可以在不命名任何退化族的前提下覆盖组合工作点。

可证伪的形式：见 §7。

## 2. 表示：为什么是场，而不是算子编号

现有增强的表示是离散的：`(算子 id, 强度)`。离散表示有两个死结：
族标签未知时无法分配到 id；族标签已知时它也只能表达那 15 种。

连续场表示把退化写成加性-乘性合成模型：

```
x_deg = clamp( K ⊙ x_clean + N )      K ∈ [0,1]^{H×W×1},  N ∈ R^{H×W×3}
```

- 雾、云：K 低（透射率场），N 为散射项 `A(1−K)`；
- 眩光、过曝：N 大且局部（bloom）；K 高；
- 噪声：K = 1，N ~ 零均值随机场；
- 模糊：K 退化为卷积核（见 §2.1）；
- JPEG/pixelate：K、N 都表达不了 → **明确声明该表示族外的退化不在此方法覆盖范围**。

这个表示刻意覆盖了本项目已有的物理渲染器（haze 用 Koschmieder 透射、glare 用镜面瓣 + bloom），
所以它与 §8.4 的实验是同一族模型，不是新发明。

### 2.1 模糊的并入

模糊是线性算子而非逐像素增益。用**可分离的局部核场**：

```
x_deg = Σ_{Δ} K_Δ ⊙ shift(x_clean, Δ) + N,   Σ_Δ K_Δ = 1
```

即把"每像素一个权重"换成"每像素一个小核（如 5×5）上的权重分布"。参数量 ×25，
但仍可预测、可平滑、可复合。

## 3. 模块

### 3.1 F_θ：场估计器

输入一张（可能已退化的）图像 `x ∈ R^{H×W×3}`，输出 `(K, N, σ)`。

```
backbone: 3 级 stride-2 conv（32×32 → 4×4），U-Net 解码，通道 32/64/128
heads:    K 头（sigmoid）、N 头（线性）、σ 头（全局标量，softplus）
capacity: K、N 预测在 8×8 网格上（stride 4），双线性上采样回 32×32
```

**8×8 网格是设计的一部分，不是省算力**。相位 0/1 的测量（§8.5）说明：全分辨率 N
可以把图像抄进去，重建损失对此毫无抵抗。低分辨率场在物理上也是对的——透射率、环境光、
炫光都是低频的——同时它在结构上排除了抄图。

**σ 是标量而不是场**：白噪声的**实现**是高频的，把某张图的噪声实现迁移到别的图上没有意义
（相位 0 已实测为负）；可迁移的是噪声**幅度**。所以 `N` 只含结构化加性成分，
`σ` 每图一个标量，合成训练样本时按该 σ 重新抽一次噪声。

训练数据**不需要任何族标签**：从内容集 `X_clean`（有标签的训练图像）与一个
**连续先验** `p(K,N)` 采样，合成 `x_deg`，令估计器回归场（或直接用重建损失）。
连续先验的定义见 §3.2，它**不包含**测试族的离散枚举。

损失（第三版，前两版都已实测失败，见 §8.5）：

```
L = ‖K̂ − K‖₁ + ‖N̂ − N‖₁ + |σ̂ − σ| + ‖ clamp(K̂ x + N̂) − x_deg ‖₁
```

场是生成样本时**已知**的：先验自己的输出就是监督。这不违反"无族名"——先验里没有族，
只有物理参数。K̂、N̂ 与真值在**同一 8×8 网格**上比较，不因为分辨率不及而受罚。

推理时（部署图像无干净配对）：只取 `(K̂, N̂)`，不重建。场的歧义（雾和"深色内容"难分）
由平滑正则与内容先验抑制。

### 3.2 连续先验 p(K, N)

从物理参数化采样，而不是从族名采样：

| 分量 | 参数 | 采样范围 |
|---|---|---|
| 无退化 | — | 概率 0.12，返回 K=1, N=0, σ=0（估计器必须见过干净样本） |
| 透射场 K | 低频 Perlin 场，均值 t | t ~ U(0.15, 1.0)，2–4 个倍频 |
| 散射项 | 大气光 A | A ~ U(0.6, 1.0)³ |
| 眩光/加性 | 高斯瓣中心 (u,v)、σ、幅度 | 位置均匀，σ ~ U(2, 10) px，幅度 ~ U(0, 1.0) |
| 核场 | 核尺寸、各向异性、方向 | 3/5 px，比例 U(0.5, 1)，方向 U(0, π) |
| 噪声 | 高斯/泊松的 σ | σ ~ U(0, 0.08) |

**关键约束**：先验里**没有**族名，也没有"severity 1–5"的分级；族的身份是场空间中的区域，
不是枚举项。这正是"未知族"能进来的原因（若真能进来——见 §7 的证伪条件）。

### 3.3 S：联合覆盖采样器

1. 用 F_θ 在**无标签部署图像集**上估计场 `{(K_i, N_i, σ_i)}`，存成场库
   （`scripts/cifar_field_bank.py`）——只存 8×8 的估计结果，不存图像；
2. 训练时直接对场库做重采样。**低维潜变量拟合作为可选加强**，不是第一版的必需项：
   场库本身只是部署分布的样本，复合才是覆盖主张的载体；
3. 采样：
   - **单场**：从拟合分布抽 `z`；
   - **复合场（本模块的核心）**：抽 `z₁, z₂`，按顺序作用
     `x' = apply(F(z₂), apply(F(z₁), x_clean))`。
     复合分布在联合潜空间上拟合（若部署集中存在组合图像）或在边缘上做耦合（否则）；
4. 每张干净训练图像以 0.5 的概率被替换为 `x'`（与现有所有臂同一速率），
   其余保持不变；几何增广不动。

复合**必须在场空间里做**，不能在像素层面随机叠加两个算子——后者等价于"更强增强"，
而诊断说的是"联合区域的覆盖"。这也是本模块与 AugMix/PixMix 的本质区别。

### 3.4 分类器训练

与现有全部臂完全相同的协议（ResNet-18 CIFAR stem、200 epoch、SGD 0.1、cosine、
`corrupt_probability = 0.5`），唯一差别是退化样本的来源换成 S。保证与 Table 1 可比。

## 4. 与现有基线的位置

| 臂 | 训练时见过被测族？ | 表示 | 复合建模 |
|---|---|---|---|
| clean | 否 | — | — |
| AugMix | 否 | 固定算子 | 混合但不对应部署 |
| otheraug（已有） | 否（族不相交） | 固定算子 | 否 |
| lattice k=15（已有） | **是** | 固定族 | 是（配对池） |
| **NCF** | **否** | 连续场 | **是（联合采样）** |

上界是 lattice k=15（87.88%）；下界是 AugMix（78.72%）与 otheraug（待测）。
NCF 的合格线不是"超过 AugMix"，而是**在未知族条件下接近已知族上界**。

## 5. 评测协议

在同一 601 条件网格上，按**族先验的包含程度**分三档：

- **A 全含**：估计器先验覆盖全部 15 族 → 检验表示能力（应逼近 87–88%）；
- **B 留出族**：场库里**不出现** fog/frost/snow 三个族（先验本身仍是全族的物理参数化，
  被拿掉的是部署池），测试所有含这三族的条件 → **这是 P10 的直接重测，也是模块成败的关键**。
  注意这与论文主体的留出设计不同：主体留出的是 5 个**配对**，这里留出的是**族**，
  因为"估计器没见过这个族"才是未知族问题；
- **C 海事**：haze+glare 的物理重渲染（§8.4）作为真实部署族，检验跨数据集形态。

指标：配对条件精度、留出对精度、`delta`（超额）、干净精度；全部与 Table 1 同口径。

## 6. 消融（每一项都必须做，否则不能声称模块有效）

1. 场表示 vs 算子编号表示（同一估计器、同一采样器）；
2. 单场采样 vs **复合**采样（本模块的核心主张）；
3. 均匀采样 vs 从部署分布采样（是否真的需要估计部署族）；
4. 有/无平滑正则；有/无内容先验；
5. 与 lattice k=15 的嵌入差异：NCF 合成样本与真实退化图像在特征空间的分布距离。

## 7. 证伪条件（写在实现之前）

- **F1**：若 B 档（留出族）NCF 的配对精度与 AugMix 差 < 2 pp → 连续场表示没有带来转移，
  模块失败，**论文维持诊断定位，不写方法贡献**。
- **F2**：若消融 2 显示"复合采样 = 单场采样"（差 < 1 pp）→ 本模块的核心主张（联合覆盖）
  不成立，退回"部署感知增强"这一较弱说法。
- **F3**：若 A 档都不能接近 lattice k=15（差 > 5 pp）→ 场表示本身不足，先修表示再谈迁移。

三条任一触发，都按 §8 的诚实规则处理：写进论文的负结果，不重新定义指标。

## 8. 与论文的关系

- 当前论文（诊断）**独立成立**，不依赖模块结果；
- 模块若通过 F1/F2 → 论文改写为"诊断 + 方法"，摘要与 §4.7 的主张可扩到未知族；
- 模块若失败 → 现有论文不动，模块作为 negative result 的附录或下一篇的工作。

## 8.5 阶段记录（写于实现过程中，只记测量，不记期望）

**Phase 0（表示容量 / 内容迁移）** — `scripts/cifar_field_probe.py`，结果 `reports/FIELD_CAPACITY.md`。

- 已知干净图像的逐图拟合：15 族全部达到 ~40 dB。**但这不说明任何事**：K=1 时加性场 N
  可以复制任意目标，表示本身是通用的。
- 真正的检验是**跨内容迁移**：在图像 i 上拟合 (K,N)，作用到图像 j，与该图真实退化比较。
  **结果是否定的**：15 族里 12 族的迁移 PSNR 低于恒等（MSE 减少量为负，例如
  gaussian_noise −1.09、defocus −2.46、pixelate −2.63）；只有 brightness（+0.76）、
  frost（+0.58）、snow（+0.34）为正。复合条件里 frost+snow（+0.77）为正，
  噪声与 jpeg+pixelate 复合为负。

> 结论 1：逐图优化拿不到"退化"，只能拿到"这张图"。场的估计必须来自
> **见过大量内容 × 大量场的估计器**，把内容留在图像通路上。

**Phase 1 第一版（估计器，重建目标）** — `scripts/cifar_field_train.py`，
`src/maritime_robust/cifar_field_estimator.py`。**失败，且失败原因已定位。**

- 训练只用 `sample_field` 的连续先验（物理参数，无族名），目标是
  `‖ clamp(K̂ x + N̂) − x_deg ‖₁` + 平滑。
- 训练损失降到 rec 0.0056，看起来收敛。但 6000 步后在 15 族上
  **0 族的迁移为正**，且迁移 PSNR 9.6–17.9 dB **低于恒等**（18.0–31.1 dB），
  即估计出的场比什么都不做更糟（`reports/FIELD_ESTIMATOR.md`）。

失败是**目标函数退化**，不是表示的极限。`scripts/cifar_field_diagnose.py` 直接测出来：

| 输入 | 应得 | 实测 |
|---|---|---|
| 干净图像（无退化） | K = 1, N = 0 | **K = 0.034，N ≈ x，corr(N, x) = +0.993** |
| 已知场生成的退化 | K̂ ≈ K, N̂ ≈ N | K 误差 0.824，N 误差 0.405 |

即网络学到了 `K = 0, N = x_deg`：每像素一条方程、四个未知数，这个解对任何目标都精确成立。
它没有估计退化，只是把输入抄进了加性场；把"这张图"作用到另一张图上，自然比恒等更差。

> 结论 2：`x_deg = K ⊙ x + N` 单独**不可辨识**。仅靠重建损失，
> 场的估计一定塌缩到抄图。要估计退化，必须给分解加一个它自己满足不了的约束。

**Phase 1 第二版（等变惩罚）** — 一个场同时作用到**两张不同的干净图**，要求两次估计
给出同一个 (K, N)：

```
d₁ = F(x₁), d₂ = F(x₂)         同一个 F
L = rec(d₁,x₁) + rec(d₂,x₂) + λ·(‖K̂₁−K̂₂‖ + ‖N̂₁−N̂₂‖)
```

内容无法进入 N：两张图内容不同，N 却必须相同。**失败，但失败方式是可诊断的**：
等变项被"无视输入"满足——step 200 起场在批内的离散度（spread）就塌到
`0.0000/0.0004`，即估计器对任何输入都输出同一个常数场。rec 卡在 0.067 不再下降。
一个常数场确实满足约束，也几乎不带来信息。

> 结论 3：等变**惩罚**不够。要么把它变成结构约束，要么直接给场监督。

**Phase 1 第三版（结构容量 + 直接监督）** — 两处改动，都是被上面的测量逼出来的：

1. **场在 8×8 网格上预测**，双线性上采样到 32×32。这是结构性的容量限制，不是正则：
   全分辨率解码器可以把图像抄进 N，而惩罚拦不住。物理上这也对——透射率、环境光、
   炫光都是低频。
2. **场的监督来自生成器本身**：先验画出 (K, N, σ)，它们就是标签。这不引入族名，
   先验里只有物理参数。K̂、N̂ 与真值在同一 8×8 网格上比较。
3. **σ 是标量**：白噪声的实现高频、不可迁移（相位 0 已实测），可迁移的只有幅度。

监视的三个量：K̂(clean) → 1；N̂(clean) → 0；spread 非零。

**Phase 1 第三版结果** — `reports/FIELD_ESTIMATOR.md`（12000 步）。三个可辨识性指标全部达成：
K(clean) 0.976（目标 1）、N(clean) 0.021（目标 0）、corr(N, x) +0.196（原塌缩解是 +0.993），
批内 spread 0.13–0.15（原来 0.000）。**塌缩解被消除了**。

这一版把先验加宽了（先验里加了 p=0.12 的"无退化"分支，透射率 t ~ U(0.15, 1.0)，
眩光幅度 ~ U(0, 1.0)，噪声 σ ~ U(0, 0.12)），理由是估计器从未见过 K=1, N=0，
在干净图上会报出一个虚假的小场。加宽后正向迁移的族从 3 个变成 4 个。

迁移表要分两类读，否则会误判：

- **白噪声三类**（gaussian / shot / impulse）的"MSE removed"是 −1.20、−1.30、−0.97，**这是指标
  的构造极限，不是失败**：估计得完全正确时，预测噪声与目标噪声是两次独立抽样，
  `E‖ε₁−ε₂‖² = 2σ²`，相对恒等的 MSE 恰好是 −1。实测 ≈ −1.2 说明 σ̂ 略偏大（约 10–20%）。
- **确定性族**（15 族里 4 个为正）：frost +0.52、brightness +0.21、snow +0.14、fog +0.05；
  contrast（−0.10）、elastic（−0.03）持平；模糊、pixelate、jpeg 为负——这些
  **本来就不在场表示里**（§2：模糊需要核场，压缩与像素化不在族内）。
  复合条件里 frost+snow +0.60、fog+contrast +0.22 为正，噪声复合 −1.13（同上，指标极限）。

**Phase 2 场库** — `scripts/cifar_field_bank.py`，A 档 1200 个场（15 族 × 5 级 × 16 图）。
估计出的场随严重度单调、且按族分离（干净背景上 fog 的 K̂ 由 sev1 的 0.947 降到 sev5 的 0.719，
|N̂| 由 0.042 升到 0.235；gaussian_noise 的 σ̂ 为 0.074），说明估计器确实在度量退化而不是输出常数。

**但幅度是压缩的**：真实 fog sev5 的透射率约 0.2，估计器给出 0.72。8×8 网格平均掉了
CIFAR-10-C 雾场的空间高频结构，这是 §3.1 说的结构容量限制的直接代价。因此场库单场偏弱，
复合两个场才达到 sev-3 级别的强度。这一条写进论文时必须如实陈述——它也是 F1 若失败时的
第一个可疑原因。

**Phase 3 第一版训练臂（tier A，m=1）— 不通过，原因已定位。** `ncf_c_a_s17`：
clean 95.08、单族 87.75、**复合 77.46**。对照 AugMix 78.72、k=15 87.88，
F3（距 k=15 ≤5 pp）差 10.4 pp，判定失败。

失败模式很干净：单族（87.75）已经接近 AugMix（88.95）、干净精度只掉 0.39 pp，
说明场增广**不是无效，而是只在低严重度有效**。原因是幅度，不是表示。
`scripts/cifar_field_calibrate.py` 用部署池自己的 PSNR 标出来：

| 采样方式 | 平均 PSNR (dB) | 对照 |
|---|---:|---|
| 单场，作用 1 次 | **40.00** | 真值 sev1 = 27.27 |
| 复合 2 场，各 1 次 | 29.50 | 真值 sev3 = 21.96 |
| 复合 2 场，各 2 次 | **20.48** | 真值 sev5 = 19.37 |

即整个 `ncf_c` 臂实际是在**约 sev-1 强度**上训练的：40 dB 的"退化"几乎等于原图。
这解释了为什么它的净效果和 AugMix 同档——增广太浅，severe 复合条件根本没被覆盖。

修正不需要重训估计器，只需要改变场的应用次数（仍在表示内：一个场作用 m 次仍是场）。
按"匹配部署池 PSNR"标定得 m=2（复合两场 → 20.48 dB，对齐 sev-3）。第二版臂
`ncf_c_a_r2` / `ncf_c_b_r2` 用 m=2 重跑。标定用的目标只有 PSNR 分布，**不看精度**，
所以不是拿测试集调参。

**Phase 3 第二版（标定后，m=2）— 总体仍不通过，但边界量出来了。**

三条已登记的判据：**F1 失败**（tier B 78.06 vs AugMix 78.72，差 0.66 pp < 2 pp）、
**F3 失败**（77.61 vs 87.88，差 10.3 pp）、F2 方向为正但幅度只有 +2.0 pp（78.06 复合 vs 75.63 单场，
两者标定不同，需在 m=2 下重测）。**按 §7，模块不能写成方法贡献。**

但失败的位置是结构性的，不是随机的。逐族单条件精度（无族名 vs 监督训练）：

> 复合精度在可表示族上从 57.3 提到 86.1（AugMix 82.7、上界 87.8），在不可表示族上停在 AugMix 水平。
> 这一条可以被写成一个有明确边界的贡献，也可以写成一个决定性的负结果——取决于是否补核场。

> 结论 4：可辨识的场估计成立，但它能覆盖的只是"全局增益 + 平滑加性 + 噪声幅度"
> 这一片区域。这正好是 §3.3 需要的：训练增广不要求单张场完全正确，要求的是
> **合成分布落在正确的区域**——这只能由下游精度判定，不能由 PSNR 判定。

### 8.6 核场扩展：卷积项能不能被估计出来

结论 5 把边界画在卷积上，所以唯一的结构性修法是给场加一个卷积项：
每图 `(σx, σy, θ)` 的各向异性高斯，作用在增益/加性之前（与生成器的物理顺序一致）。
预注册在 `reports/PREREG_NCF_BLUR.md`（B1 表示、B2 可辨识、B3 干净代价）。

**第一次训练完全失败，原因在参数化而不在表示。** 12k 步后 `blur_err` 停在 2.32，
诊断脚本 `scripts/cifar_field_blurdiff.py` 给出决定性读数：预测 σx 均值 **0.000**、
MAE 0.953，与"永远预测均值"的基线 0.940 相同、相关系数 **−0.48**——头部根本没离开初始化。
两个具体缺陷：

1. 输出层 bias 初始化为 −6，`softplus(−6)=0.0025`，其导数也是 0.0025；再乘 `blur_w` 和 lr 2e-4，
   bias 每一步只动 1.5e-7，12k 步只走了 0.13。
2. θ 用 `atan2(cos, sin)` 参数化，初始点 `raw=(0,0)` 处梯度为零，角度从第一步就锁死。

还有一处是目标本身的错：先验有一半样本无模糊，其角度目标是占位值 0，
却与模糊样本同等加权，等于把头部往"θ=0"推。副作用可见——σ 的监督同时退化
（0.0015 → 0.0305），因为不可学的模糊项污染了共享主干。

**修正**（均在 `cifar_field_estimator.py`）：bias 初始化到 σ≈0.6（导数 O(1)）、
`θ = π·sigmoid(raw)`、角度项只在真有模糊的样本上监督、`blur_w` 0.3→0.5。重训 12k 步：

| 指标 | 修正前 | 修正后 |
|---|---:|---:|
| 训练 `blur_err`（σx+σy+角度） | 2.32 | **0.37** |
| 合成诊断 σx MAE（预测均值基线 0.940） | 0.953 | **0.109** |
| 合成诊断 σx 相关 | −0.48 | **+0.978** |
| σ 噪声误差 | 0.0305 | **0.0045** |
| 跨内容正迁移族数 | 4/15 | **6/15** |

真实族上的 σ̂（sev3，64 图）：motion 0.80/0.40、zoom 0.61/0.51、defocus 0.31/0.29；
其余十二族 ≤0.21（pixelate、glass、snow、frost、brightness、shot、impulse 均为 0.00）。
分离是干净的——卷积族得到非零核，非卷积族得不到——但**幅度仍是压缩的**，
和 fog 的 K̂（真值 0.2、估计 0.72）是同一个 8×8/池化结构的代价。

**B2 判定：合成条款成立（r=0.978 ≥ 0.5，MAE 降 88% ≥ 25%）；真实条款部分不成立**
（要求 defocus/motion/zoom 里至少 3 个的 σx ≥ 0.80，实际只有 motion 一个）。
如实记录，不修改门槛。迁移表上 motion（+0.083）与 zoom（+0.186）转正，
defocus 的迁移 PSNR 30.91 → 32.25 高于恒等。

### 8.7 卷积项入场后的臂（tier A，m=2）

场库重建为 `artifacts/fields_ab.npz`（1200 个场 + 核），并按 PSNR 重新标定：
混合作用次数 m=2、复合两场 → 18.99 dB，对齐部署池 sev-3 的 21.93 dB（仍是最接近档）。

## 9. 参考定位（必须引用的最近邻）

- Probabilistic Degradation Estimator, Neurocomputing 2024（盲超分中"估计参数→重合成"）：
  单退化、回归参数、用于 SR；**不复合**。
- QualNet, CVPR 2021（invertible decoder，质量不可知识别）：目标是表示不变性，
  不是训练数据覆盖；不可组合。
- AugMix (ICLR 2020)、PixMix (CVPR 2022)：固定算子集合，与部署族无对应。
- 本文 §8.4 物理渲染器：场表示的物理特例，已实测可用（+14.6/+21.8 pp 超额复现）。

**与它们的分界线只有一句**：已有工作覆盖"单退化"或"任意扰动"，本文覆盖的是
**测量出来的组合失效点**，且覆盖发生在**场空间的联合分布**上。

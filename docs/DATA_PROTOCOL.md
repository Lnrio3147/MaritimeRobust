# 数据准入和标签边界

## FGSC-23

数据通过作者仓库公布的 Google Drive ID `1_Y7UtN-Y0v3w4NEMIrdPbg80_05bo9is` 获取；包内 README 与作者仓库的标签说明匹配。原包保留在 `data/raw/fgsc23.archive`，下载包和清单 SHA-256 记录在工件中。实际包包含 4,080 张图；不同论文关于 4,052/4,080 的描述不替代实际审查。

主任务只纳入确定的民用类别：14 container ship、15 car carrier、17 bulk carrier、18 oil tanker、19 fishing boat、20 passenger ship、21 liquefied gas ship、22 barge。medical ship、auxiliary ship、hovercraft 的军民用途不确定，排除出主任务。类别编号被重映射为连续训练标签，原编号仍保存。

标签名称表示船型，不代表建造型号或船只 ID。清单内 source_scene_id、port_id、vessel_id 没有证据时为空。

## 划分与重复审查

读取所有图像只用于文件完整性、像素哈希和近重复筛查。模型选择从不使用测试分类指标。

- 文件 SHA-256、解码像素 SHA-256 双重记录。
- 近重复候选条件：32×32 缩略图 63-bit pHash 汉明距离≤4；只有 RGB 缩略图平均绝对差≤0.035 的候选才合并为保守重复组。保存全部候选供复核；跨划分组已生成人工检查接触表。
- 官方协议保留原 train/test；从原 train 内按重复组和类别划出约 20% 验证集。已发现的官方跨划分关联如实披露。
- 研究协议折叠完全相同像素，排除含矛盾标签的重复组；保留官方测试图及其关联组为研究 test，从其余组中划出 train/val。研究 test 因此可能包含原 train 图像。
- 主实验训练、验证、测试之间的已识别重复组交集必须为零。清单排序和划分种子固定为 20261027。

这只能证明已识别的重复组隔离。缺少原始场景和港口信息，不能证明港口、船只或采集时间独立；保守 pHash 筛查也可能漏掉旋转、变焦和重裁剪近重复。论文需要同时披露这一限制。

## FGSRCS

作者仓库明确包括 17 类、280 个港口和真实浓云、薄雾、阴影、海杂波、地面设施复杂场景；作者仅允许学术使用。实际作者包含 4,500 张原图（作者 train 3,150 / val 1,350），4,500 个解码像素互异的原图组；二级标注共 11,187 个目标，全部成功裁剪，无几何无效目标。17 类中民船相关裁剪 862 个（container-ship 211、oil-tanker 290、cruise-ship 173、sand-carrier 188）；其余为军舰类别。数据集级场景描述不等于逐样本退化标签。

真实目标裁剪以作者多边形标注为依据：取轴对齐外接矩形，四周各增加框宽/高的 10% 上下文，截到图像边界，保留比例并补边。记录原图、多边形、裁剪坐标和目标 mask；原图 group 为划分单位。检测困难样本不删除，仅记录 difficulty。每个目标另存一个标注多边形区域 mask，它不是像素级船体分割。

真实数据只准备后续验证。按原图组以稳定哈希划分：开发 1,350 个原图组（3,448 个裁剪），封存 3,150 个原图组（7,739 个裁剪），组交集为 0；作者 val 原图组全部进入封存，不参与开发。若更高层港口/时相身份缺失，不声称完成港口/时相独立验证。不为满足比例拆散同一原图；少样本类的划分不足明确记录。

原图组只按完全相同的解码像素合并；同场景不同裁剪、旋转、时相或重编码造成的近重复未被合并，开发/封存仍可能包含近重复场景。跨库筛查只针对 FGSC-23，不证明 FGSRCS 内部场景独立。因此当前划分只能保证“已识别精确重复组”隔离，不能保证场景级独立。

跨库映射仅直接采用 container-ship→container ship、oil-tanker→oil tanker。cruise-ship 是 passenger ship 的子类，sand-carrier 与 bulk carrier 不等价，两者暂不纳入严格跨库同标签评分。

跨库筛查以精确解码像素 SHA-256 和 63-bit 缩略图 pHash（汉明距离≤4）加 32×32 RGB 平均绝对差≤0.035 的保守近重复条件，对 FGSC-23 研究清单 4,071 张、FGSRCS 4,500 张原图和 11,187 个裁剪进行比较，精确匹配 0 对、近重复候选 0 对（`reports/cross_dataset_overlap.json`）。该负结果只说明在本筛查条件下未发现重叠；缩略图无法可靠检测裁剪、旋转、缩放或重处理，且两库均缺少港口/时相身份，因此不能证明场景或港口独立。

未来真实退化标签需由图像审阅建立：类型可多选、强度轻/中/重/无法判断；当前不根据图像亮度自动伪造雾/云标签。开发数据可用于制定标注细则，封存测试不用于调参。本轮未计划在真实测试集上开展创新模块实验。

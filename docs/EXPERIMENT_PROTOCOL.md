# 实验协议 v1.1（首轮 + 组合增强基线）

## 模型、训练与选择

使用 torchvision ResNet-50 ImageNet-1K V2、ConvNeXt-Tiny ImageNet-1K V1、Swin-T ImageNet-1K V1，下载权重做 SHA-256 校验。全部参数参与训练，输入 224×224，长边缩放后补边，ImageNet mean/std 归一化。几何增强仅包括水平/垂直翻转和 90 度旋转，不随机裁掉细粒度结构。

固定 40 epoch、batch 32，无测试集调参。ResNet-50 用 SGD(lr=0.01,momentum=0.9,weight_decay=1e-4)，其余两种用 AdamW(lr=1e-4,weight_decay=0.05)，余弦学习率，交叉熵，梯度范数裁剪 5，float16 AMP。若发生非有限损失立即停止。训练和验证固定随机种子，数据增强随机数由样本 ID、epoch 和种子决定。

研究协议的 civilian/all 分别训练干净与增强版本，首种子为 17。首轮单退化增强版本每个样本每个 epoch 以 50% 概率保持干净，剩余概率等分为雾、云、眩光，强度均匀取 1–5。干净与增强版本训练步数和几何增强一致；shifted 分布不进入训练。

第二轮增量增加“组合退化增强”基线，单独使用 `configs/combined_augmentation.json`（哈希写入运行配置），不修改首轮 `configs/degradations.json`，因此既有运行可回放。配方与单退化增强预算匹配：每个样本每个 epoch 以 50% 概率保持干净；在退化抽样中，50% 为单退化（雾/云/眩光均匀，强度 1–5），50% 为组合退化（雾+眩光或雾+云均匀，强度 3 或 5，matched 域、随机位置）。组合强度与测试中的组合条件一致；全部组合仍只作为训练增强，不改变测试条件定义。该基线覆盖 civilian/all 两个范围，ConvNeXt-Tiny 与 Swin-T 使用种子 17/29/43，ResNet-50 使用种子 17，与首轮单退化增强的可比设置一致。它是第二轮新模块的对照基线，不是新方法。

每次训练仅用干净验证 Macro-F1 选 checkpoint，平局保留更早 epoch。完成首种子后在验证集评估干净与 15 个 matched 单退化条件：每个训练版本的得分为 0.5×干净 F1+0.5×15 条件平均 F1。两种版本得分平均后，对架构排名；每个类别范围选前两种架构补种子 29、43。选择及配置/配方哈希保存后才开始测试。领域方法席位取舍见文献表。

组合增强基线不参与首轮架构排名，直接沿用已选架构和种子，并在完整 43 个测试条件上评估；同样只用干净验证 Macro-F1 选 checkpoint，不按测试组合条件调参。报告将单退化增强与组合增强分开聚合，配对比较仅在同协议、同范围、同模型、同种子内进行。

官方完整标签参考只训练干净版本种子 17。因为保留训练内验证且已披露重复关联，不称为逐项完全复现论文训练协议。

## 测试条件

共 43 个条件：干净 1；matched/shifted 各 15 个单退化和 4 个组合条件，共 38；另有云/眩光三级强度的 center/border 空间诊断 4。所有模型使用相同样本条件和参数实例。

参数文件 `configs/degradations.json` 与实际代码定义必须一致。校准只读取验证样本，预览位于 `reports/validation_calibration.png`。退化在缩放后、补边前的图像内容上施加；因此实验研究的是固定识别分辨率下的退化。

- 雾：I=Jt+A(1-t)，五级平均透射率 0.85/0.70/0.55/0.40/0.25，叠加平滑变化。不使用伪造深度，t 不是实测大气量。
- 云：平滑随机场和空间中心控制分布，五级名义覆盖面积 15%–55%、最大 alpha 0.25–0.85，边缘平滑。面积是合成支持域占图像内容的比例。
- 眩光：局部 Gaussian 亮度叠加并截断，记录强度、中心、尺度和饱和面积；这是近似过曝/泛光模型。
- shifted：改变随机场尺度、亮斑位置分布与雾 airlight 分布。这是同一近似合成器的参数分布偏移，不是独立真实域或独立合成器证据。
- center/border：固定空间位置作受影响区域对照。FGSC-23 中央 50% 矩形仅为位置代理；无 mask 时真实目标覆盖值为空。
- 深度条件雾（2026-10-29 新增，**不属于**上述 43 条件，也不改动 `degradations.py`）：
  `src/maritime_robust/depth_fog.py` 用 I=Jt+A(1-t)、t=exp(-βd) 施加雾，d 为单体深度归一化到
  [0.15, 1]，β 取使**最远处**透射率等于原五级 0.85/0.70/0.55/0.40/0.25 的值，因此两套雾在远场
  可比。近场透射率更高（三级时上限约 0.91），故同级别下深度雾的平均透射率高于平坦雾
  （三级 0.65–0.74 vs 0.55），比较时必须按"远场透射率对齐"读，而不是按平均透射率。
  深度提供者：`flat`（深度无信息对照）、`horizon`（几何先验，仅适合侧视海面）、
  `depth-anything`（Depth Anything V2 Small，HF 权重，离线缓存到 `artifacts/depth_cache/`）。
  条件名：`{matched,shifted}_depth_haze_{1..5}` 与 `depth_haze+glare`、`depth_haze+cloud`（3/5 级），共 18 个。
  在俯视航拍图上单体深度信息弱（`depth-anything` 的透射率空间跨度约 [0.25,0.81]），
  深度条件化的收益主要体现在侧视/水平线场景；该结论须在报告里披露。

DCP 对每个类别范围的验证集首选架构之干净训练版本执行，覆盖三个种子和全部条件；同时保留原分类器输出。DCP 用暗通道、airlight 估计及 guided-filter 细化透射率。去雾费用计入端到端延迟。

## 指标、统计与成本

主指标是固定完整标签集合的 Macro-F1，附准确率、平衡准确率、逐类召回/F1、混淆矩阵。记录干净到各条件的下降、最差条件、正确到错误翻转、高置信错误及原图尺寸/饱和面积/中心代理覆盖的描述性关系。相关性不解释为因果。

多种子报告均值和样本标准差。单运行置信区间按 source_group_id 的完整组重采样，300 次 percentile bootstrap；没有场景 ID 时单位为重复组件。清单内所有原图副本共同重采样。没有 mask 的覆盖分析不用于支持船体定位结论。

成本：记录训练墙钟时间（含运行内 CPU 准备与验证）、预训练权重下载、参数量、峰值显存和 batch=1 的端到端延迟（20 次预热、100 次测量，中位/P95）。单卡独占运行时间保守计入 GPU 小时。torch profiler 的 FLOPs 只包含受支持的算子，标明为不完整计数，不与文献总 FLOPs 混比。

预算由文件锁和持久账本约束：preflight 8h、baseline 24h、augmentation 24h、evaluation 16h、总计 72h；每批检查时间，定期检查项目 50GB 上限。正常失败与重跑均计费；突然断电至最后心跳之后的一小段时间可能未入账。原始数据下载单独记录，不占 GPU 计算工时。

## 验收

必须从保存预测重算指标；checkpoint 重载概率最大误差≤1e-5；研究划分 group 交集为零；所有测试条件参数可回放；工件哈希可验证。组合增强运行还须绑定 `configs/combined_augmentation.json` 哈希与训练源码哈希；报告按训练配方分开聚合。先报告实际完成项，再报告外部代码/权重访问缺口。不因结果不好删除种子或失败实验。

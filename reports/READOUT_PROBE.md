# s=5 的跳变是读出层产物吗？——D3 读出探针

2026-10-30。预注册 `PREREG_READOUT_PROBE.md`（写于运行前）。只训练读出层，骨干冻结。

## 1. 做法

冻结基线骨干 `convnext_tiny_none_e40_s{17,29}`（fold0）的 768 维描述子，L2 归一化。两个读出，**只用 clean 训练特征拟合**：

- `logreg`：多项逻辑回归（C=1）；
- `prototype`：类质心余弦最近邻。

评测 45 个条件，超加性 `E_acc` 与 D2/草稿同式。脚本 `scripts/readout_probe.py`，产物 `reports/readout_probe_s{17,29}.json`。

## 3. 对照预注册判定

| 编号 | 预测 | 结果 |
|---|---|---|
| P1 | 至少一种读出把 E_acc(5) 降到 ≤+4.9 pp，clean 损失 ≤1 pp | **不成立**：两种读出都在 +10.7…+17.0 pp，clean 也更低 |
| P2 | prototype 在 s=5 的绝对准确率不低于模型 | **不成立**（52.43 vs 55.34 / 53.88） |
| P3 | 两种读出在 s=2–4 的 E_acc 接近 0 | 大体成立（−1.9…+3.9 pp） |

## 4. 这说明什么

1. **跳变不是分类头造成的。** 换成在干净特征上重新拟合的线性/原型读出，s=5 的超加性不减反增，绝对准确率还更低。学习到的分类头反而是目前最好的读出。
2. 结合 D2：表征漂移在低严重度就平滑积累，行为跳变出现在 s=5，且换任何读出都保留 → 跳变位于**表征几何**：s=5 复合把特征推进了边际退化张成的区域之外。
3. 因此"调分类器/校准头"这条路没有证据支持，按预注册应关闭。

## 5. 下一步

唯一未分辨的是这个区域**还剩多少信息**：是配比/容量问题，还是饱和抹掉了类别证据。`PREREG_SPECIALIST_PROBE.md` 用专训 s=5 复合的模型给出上界判据（≥+10 pp → 信息仍在；≤5 pp → 信息受限）。

## 6. 边界

- 读出只拟合 clean 特征，不含退化增强；因此读出在退化下更差不能单独读成"读出更好"（预注册 §5 已写明）。
- 单折、两种子、单一骨干；未做跨折。

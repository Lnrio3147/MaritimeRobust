# 预注册：复合退化鲁棒性是否为覆盖性质

写于覆盖训练开始之前（2026-10-31）。冻结预测，禁止事后挑选。

## 假设

此前所有失败的方法都假定复合退化需要**结构**处理（识别退化 → 修复、加性约束、逐图加权）。
覆盖假设给另一条路：复合退化的误差超出，源于训练分布**从未出现**这些操作点，
而不是源于模型缺少某种结构归纳偏置。

若成立，仅改变**训练时退化的采样分布**（同算力、同复合暴露量、只改配对多样性）
就应在**留出的复合对**上降低超出量。

## 设计

格子只取六个**已标定到 matched-20pp** 的连续族：defocus .41, motion .528, noise .435,
rain .392, pixelate .353, impulse .475（`reports/composition/gate_target20.json`）。

排除 haze/glare/cloud 的原因写在跑之前：sev-5 下三者不可比——haze 掉 2.0 pp、cloud 掉 3.4 pp、
glare 掉 17.5 pp。把两种量级混进同一个格子，就无法区分"配对更多"与"配对更难"。
它们只作为**迁移目标**出现。

- 15 个对；**留出 3 个**，每族恰好缺席一次：`noise+pixelate`、`defocus+rain`、`motion+impulse`。
- 训练池 = 剩余 12 对的**嵌套**前缀（族计数均衡贪心排序，前 3 对已覆盖全部六族各一次）：
  - `c3`  = defocus+impulse, motion+noise, rain+pixelate
  - `c6`  = 前 6 对
  - `c12` = 全部 12 对
- 三 arm 复合暴露量相同（每样本 50% clean / 50% 复合，复合时自池中均匀抽一对）。
  唯一变量是**池内配对多样性**。
- 训练超参与 baseline 完全一致（ConvNeXt-T, 40 ep, AdamW 1e-4, wd .05, bs 32, cosine, 6 单元）。
- 评估两套：
  - `lattice_eval`：clean + 6 单族 + 15 对，算 `delta = e(a+b) − |E_a ∪ E_b|`
  - `overlap_main_grid`：47 条件网格，取 `haze+glare_5` / `haze+cloud_5`（任一训练池都不含）

## 基线现值（未训练覆盖，训练开始前 6/6 单元已测）

留出对的 delta 按单元（6/6 单元已测，训练前完成）：
fold0/s17 +8.4、fold0/s29 +6.5、fold1/s17 +16.0、fold1/s29 +6.5、fold2/s17 +5.5、fold2/s29 +6.3，
均值 **+8.2 pp**（与论文主网格 haze+glare_5 的 +9.9 同量级）。
同一批 baseline 在**池内**（非留出）对上的 delta 均值只有 +3.8 pp——留出对确实更难，
这一点必须在判读 c12 时记住：留出对本身就是分布外。

## 冻结预测（对 c12）

| 编号 | 指标 | baseline | 预测 |
|---|---|---:|---|
| P1 | 留出对 delta（6 单元均值） | +8.2 | ≤ +5.0 |
| P2 | 剂量响应 | — | 均值 c3 ≥ c6 ≥ c12 |
| P3 | clean acc | 85.0 | 下降 ≤ 1.5 pp |
| P4 | haze+glare_5 delta（迁移） | +9.9 | ≤ +6.0 |
| P5 | 池内（非留出）对 delta 的改善 > 留出对 | — | 是 |

## 判伪

**c12 留出对 delta ≥ +7.5 pp 且 clean 未降** → 覆盖假设被否定。
届时不得改写为"部分有效"，也不得换条件重讲；直接记为负结果。

## 已排除的混杂

- **总量混杂**：三 arm 复合暴露量相同，只有多样性不同。
- **清洁精度混杂**：P3 要求 clean 不降；clean 大降则任何复合指标变化不作数。
- **配对不平衡**：前 3 对已覆盖六族各一次。
- **难度混杂**：全部族在同一条 matched-20pp 标定线上。
- **留出泄漏**：训练池不含三个留出对；`lattice_eval` 在生成时按同一 seed 独立施加。

## 修正 #1（2026-10-31，c3 第一格出结果后，主实验仍在跑）

c3 的第一个单元（fold0/s17）显示：留出对 delta 从 +8.4 掉到 −4.2。但逐项拆开看，
改善几乎全部来自**单族**错误率下降（noise 64.1→77.7、rain 61.7→76.7、pixelate 65.5→81.1），
而不是配对结构。原因是 baseline 的 combined recipe 只用 haze/glare/cloud 三个族，
其余六族**从未进过训练**。所以 baseline → c{k} 的差测的是"补上六个缺失的族"，
不是"覆盖了配对"。

审稿人会一句话打掉这个。因此新增控制臂，并把主比较改成它：

**`s6`（单族控制）**：同样六族、同样 50% clean / 50% 复合率、同样预算、同样池，
唯一区别是每次抽样只施加**一个**族而非一对。

| 比较 | 测的是 |
|---|---|
| baseline → s6 | 补上六个缺失的族（已知效应，不作为贡献） |
| **s6 → c12** | **配对覆盖本身的贡献（这才是论文的 claim）** |
| c3 → c6 → c12 | 池内多样性的剂量响应 |

新增冻结预测（对 s6 → c12 的 6 单元配对差）：

| 编号 | 指标 | 预测 |
|---|---|---:|
| P6 | 留出对 delta，c12 比 s6 更低 | ≤ −2.0 pp |
| P7 | 池内（非留出）对 delta，c12 比 s6 更低 | ≤ −1.0 pp |
| P8 | clean acc，c12 与 s6 之差 | 绝对值 ≤ 1.0 pp |

**判伪（覆盖主张）**：若 s6 与 c12 在留出对 delta 上的配对差 |差| < 1.0 pp，
则"覆盖配对"无独立贡献，论文不得声称覆盖机制；只能声称"加入标定复合增强有效"，
并明确标注该效应来自族覆盖而非配对覆盖。

P1–P5 保留，但降级为**次要**：它们混合了族覆盖与配对覆盖两种效应，不能单独支持覆盖主张。

## 修正 #2（2026-10-31，c3 的 overlap 评估出来之后，主实验仍在跑）

c3/fold0_s17 在论文主网格上的结果是：haze+glare_5 准确率 **59.0 → 35.0**，delta **+9.9 → +10.2**。

原因清楚：格子臂**替换**了项目的 combined recipe，而该 recipe 是唯一训练 haze/glare/cloud 的地方。
所以这两个族退出训练，准确率塌掉，delta 纹丝不动。

两个推论，都要写进论文：

1. **不跨族迁移**：用六个别的族做覆盖训练，对 haze+glare 的超出量没有任何作用。
2. **delta 不是余量伪影**：准确率 59 和 35 的两个模型给出同一 delta（+9.9 vs +10.2）。
   修正 #1 里担心的"余量归一化"问题，在这一对模型上被直接证伪。

新增臂 `c12b`：**base recipe ∪ 12 对格子，各 50%**。haze/glare 保持在训练里，
因此 c12b 与 baseline 的 haze+glare 比较是 like-for-like。

| 比较 | 测的是 |
|---|---|
| baseline → c12b（haze+glare） | 在**保留**原训练分布的前提下，加格子是否有迁移增益 |
| baseline → c3/c12（六族对） | 族覆盖的效应（已确认很大） |
| s6 → c12（六族对） | 配对覆盖的效应（P6–P8） |

冻结预测（c12b，6 单元）：

| 编号 | 指标 | 预测 |
|---|---|---:|
| P9 | haze+glare_5 准确率 vs baseline(0.59) | ≥ 0.57（不掉） |
| P10 | haze+glare_5 delta vs baseline(+9.9) | 变化 ≤ 2.0 pp（即**无迁移**） |
| P11 | clean acc vs baseline(0.85) | ≥ 0.83 |

P10 是**负向预测**：我预期不走样。若 c12b 反而显著降低 hg5 的 delta，那是比覆盖假设更强、
更需要解释的结果，必须优先报告而不是当作噪声。

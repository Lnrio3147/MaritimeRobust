# 预注册：测试时特征重定心能否收回复合退化的损失

2026-10-30。写于实现与评测之前。零训练、零微调，只改正已冻结检查点的推理路径。

## 1. 要测的假设

M2 与弃权探针给出同一个机制诊断：复合退化把**整片特征云同向平移**（s=5 平均漂移 0.15，cos≈0.85），而样本到各自类质心的相对位置几乎不变。九个训练时干预全部失败。若诊断正确，那么**测试时**的一次坐标平移校正应当收回大部分损失——这是唯一一个直接作用于已诊断病因、且从未被测试过的改动。

这也是本仓库目前唯一可能产出**可用方法**的方向：它要么给出一个能工作的最小校正，要么确定"复合退化不是可校正的坐标问题"，两者都可写。

## 2. 变体（全部零训练，作用在冻结基线 `convnext_tiny_none_e40_s{17,29}` 上）

记 `f` 为 `features_of(x)`（768 维池化特征），`μ_tr, σ_tr` 为该模型在**干净训练集**（412 张）上的特征均值与逐维标准差，`μ_b, σ_b` 为当前**测试条件批次**（206 张）的对应统计量。

| 代码 | 变换 | 目的 |
|---|---|---|
| C0 | `argmax(head(f))` | 恒等，必须逐图复现基线 |
| C1 | `head(f)` 减去批次类别均值 logit 后 argmax | 对照：若平移只在 logit 空间，这条就够 |
| **R1** | `head(f − μ_b + μ_tr)` | **主候选**：把整片云平移回干净训练分布的位置 |
| R2 | `head((f − μ_b)/σ_b · σ_tr + μ_tr)` | 同时恢复一阶与二阶矩（AdaBN 式） |

两者都只用**无标签**的测试批次统计量，不使用标签。

## 3. 评测

同一折 fold0 的 47 个条件（`m2_eval.conditions_47`），逐图配对，`combo_sev5_matched`（s=5 的 matched 复合条件）为主组，`combo_low`（s≤4 的 6 个 matched 复合）为次组，另报 `single` 与 `clean`。聚类 bootstrap 按 `source_group_id` 重采样，2000 次。

## 4. 判据（写死）

| 编号 | 判据 |
|---|---|
| T1 | R1 在 `combo_sev5_matched` 上增益 ≥ **+2.0 pp**，两个种子都成立，且 95% CI 不含 0 |
| T2 | clean 上 \|Δ\| ≤ 1.0 pp（不得靠牺牲干净精度换取） |
| T3 | R1 在同一组上比 C1 至少高 **1.0 pp**（证明校正属于特征空间，而非 logit 偏置） |
| T4 | `single` 组回退 ≤ 1.0 pp |

- **T1 ∧ T2 ∧ T3 ∧ T4 → 准入**：扩到 3 折 × 4 骨干，作为候选方法继续。
- **T1 不成立 → 关闭测试时校正路线**，不再试其他统计量（分位数、协方差白化、原型重估）的变体；结论写"复合退化不是批次级坐标问题"。
- R2 只作诊断：若 R2 明显优于 R1，说明二阶矩也在移动，但**不得**据此放宽 T1。
- 无论结果如何都不调参追 T1。一次定稿。

## 5. 边界与已知风险（写在这里，避免事后辩解）

1. **这是 transductive 的**：`μ_b` 需要一批同条件、同域的测试图（本实验每批 206 张）。单张图没有批次均值，因此该方法**不能**逐图部署。这是路线本身的硬限制，不是实现问题。
2. 若 R1 有效，收益可能来自"把特征推回训练分布"这一通用 TTA 效应，而非复合退化的特有结构；T3 用来区分这一点，但无法完全排除。
3. 单折、两种子、单骨干；只在 fold0 上判定，准入后才扩。
4. 与弃权探针的区别：那测的是**错误检测**（失败），这测的是**误差校正**（可不可能）。两者不互推。
5. 本预注册不涉及任何训练改动；若准入，后续训练侧工作另行预注册。

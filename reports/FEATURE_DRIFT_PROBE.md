# 超加性在表征里还是决策里？——D2 表征漂移探针

2026-10-30。预注册见 `PREREG_FEATURE_DRIFT.md`（写于计算之前）。只推理，不训练。

## 1. 做法

基线模型 `convnext_tiny_none_e40_s{17,29}`（fold0），取 `features_of` 的 768 维描述子。对 45 个条件（43 个注册条件 + 预注册补的复合 s=2/4）：

- 漂移 `D(c) = 1 − mean_i cos(f_clean, f_c)`，逐图，206 张验证图；
- 加性预期 `A(s) = D(haze,s) + D(glare|cloud,s)`，同模型同图同严重度；
- 表征超加性 `E_feat(s) = D(复合,s) − A(s)`；
- 与准确率侧 `E_acc(s)`（同一次前向得到的预测）并列比较。

脚本 `scripts/feature_drift_probe.py`，产物 `reports/feature_drift_s{17,29}.json` 与逐图 npz。区间为按 `source_group_id` 聚类的 bootstrap 95% CI（2000 次）。

## 2. 结果

`E_feat`（haze+glare），两种子：

| 严重度 | s17 | s29 | 准确率侧 E_acc（s17 / s29） |
|---|---:|---:|---:|
| 2 | +0.0053 [+0.0004, +0.0101] | +0.0038 [−0.0009, +0.0087] | +0.0 / −1.5 pp |
| 3 | +0.0205 [+0.0082, +0.0327] | +0.0143 [+0.0040, +0.0251] | +4.9 / +1.5 pp |
| 4 | +0.0745 [+0.0545, +0.0947] | +0.0553 [+0.0368, +0.0741] | +3.4 / +1.9 pp |
| 5 | **+0.1495 [+0.1161, +0.1840]** | **+0.1476 [+0.1141, +0.1807]** | +9.7 / +12.6 pp |

- `haze+cloud`：s17 的 E_feat 在 s=2/3 为负（−0.004/−0.015），s=5 +0.032；s29 的 s=5 为 +0.006 且 CI 覆盖 0。与准确率侧（+3.4 / +1.5 pp）方向一致但更弱。
- 逐图定位失败：s=5 新错误（单退化全对而复合判错）30 张，漂移 0.692 vs 其余 0.476（s17）、0.696 vs 0.451（s29），**AUC 0.779 / 0.823**。
- 条件级相关：`E_feat` 与 `E_acc` 的 Spearman ρ = **0.850 / 0.795**（8 点，p=0.007 / 0.018）。

## 3. 对照预注册判定

| 编号 | 预测 | 结果 |
|---|---|---|
| P1 | E_feat(haze+glare,5) > 0 且 CI 排除 0 | **成立**（两种子） |
| P2 | s=2/3/4 的 CI 覆盖 0 | **不成立**：s=3 两种子均排除 0，s=4 明显为正；只有 s=2 处于边缘 |
| P3 | E_feat 与 E_acc 的 ρ ≥ 0.6 | **成立** |
| P4 | 新错误图的漂移 AUC ≥ 0.65 | **成立**（0.78 / 0.82） |

## 4. 这说明什么

1. **表征漂移与行为超加性解耦。** 表征在 s=2 就已带一点超加性，并随严重度**平滑增长**（0.005 → 0.02 → 0.075 → 0.15，约四倍步进）；准确率侧的额外损失却只在 s=5 出现（0 → 4.9 → 3.4 → 9.7）。
2. 因此"组合退化在 s=5 造成了额外的信息缺失、模型因此突然崩"这一自然解释**不成立于表征幅度层面**：漂移一直在积累，模型在 s≤4 都吸收了。行为跳变更像是**漂移越过某个可用阈值**，而不是表征突然多掉一截。
3. P4 说明漂移确实携带逐图失败信号（AUC≈0.8），所以"表征无关"是错的；正确表述是**幅度相关、阈值行为**。
4. 预注册的分叉条件没有完全覆盖实际结果（P1 成立、P2 不成立同时出现），因此不能直接套用 §4 的二分决策规则。事实要求下一步直接问：**换一个读出规则，跳变还在不在**（D3）。这条已另行预注册（`PREREG_READOUT_PROBE.md`）。

## 5. 边界

- 单一骨干（ConvNeXt-T）、fold0、两种子；未验证跨折。
- 余弦漂移是幅度量，不含方向信息；方向分析（漂移是否朝向错误类原型）未做。
- 该探针只定位"哪一层没有跳变"，不构成机制证明。

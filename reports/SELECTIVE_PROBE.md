# 弃权探针：测试时可算的漂移代理打不过熵——路线关闭

2026-10-30。预注册 `PREREG_SELECTIVE_PROBE.md`（写于评测前）。无训练、无微调，只做推理与统计。

## 1. 要回答的问题

D2 的逐图漂移能以 AUC 0.779 / 0.823 定位失败，但它的定义需要 `f(clean)`——部署时不存在。能否换一个**测试时就能算**的代理，仍保留错误检测能力并超过 softmax 熵？

主候选 `drift_nearest = 1 − max_k cos(f, μ_k)`：到最近干净类质心的余弦距离。质心只用各折 train split 的干净特征，因此不依赖测试图的干净版本，也不依赖模型自己的预测。

## 3. 对照预注册判定

| 编号 | 判据 | 结果 |
|---|---|---|
| G1 | `combo_s5`：均值 ≥ +0.05 且 ≥5/6 单元为正 | **不成立**：均值 **−0.020**，正单元 **0/6** |
| G2 | `combo_low`：同上 | **不成立**：均值 **−0.034**，正单元 **0/6** |
| G3 | `single`/`clean` 不得倒退超 0.05 | 成立（均值 −0.031 / −0.024） |
| | **准入** | **否** |

循环对照：`drift_pred` 与 `drift_nearest` 的差在 ±0.015 内，六个单元都是同一个方向。**问题不在循环性，在信号本身。**

## 4. 这说明什么

1. **D2 的漂移能力来自"配对"，不来自"距离"。** 强信号的形式是 `1 − cos(f_clean, f_c)`——同一张图的两个版本。去掉干净参考后，剩下的任何距离（最近质心、预测类质心）都退化为一个**比置信度更差的**不确定性估计。
2. 机制上说得通：复合退化把整片特征云**同向推移**（D2 测得 s=5 平均漂移约 0.15，即 cos≈0.85）。整云一起移动时，样本到最近质心的距离几乎不变，而分类器自己的概率质量会明显变化。熵看到的正是后者。
3. `unc` 与 `margin` 与 `ent` 基本同分（±0.01），说明在 6 个单元上一族置信度分数彼此不可区分——不存在"换一个置信度就赢"的空间。

## 5. 按预注册关闭

预注册 §5 写死：不通过 → 关闭弃权方向，不再试其他距离、马氏距离、余弦半径等变体。已照办。

**结论写死**：在这套协议下，置信度已是更好的错误检测器；D2 的逐图漂移只有**诊断**价值（需要配对参考），没有**部署**价值。

## 6. 边界

- 单骨干、单渲染协议；3 折 × 2 种子，每折 206 张 val。
- 质心来自同一模型的干净训练特征，与模型同源；跨模型迁移未测（不在本预注册范围）。
- 逐条件计算 AUROC，不跨条件池化；某条件全对或全错时该条件跳过（本实验中未发生）。
- 本探针不涉及任何精度改动，只测错误检测。

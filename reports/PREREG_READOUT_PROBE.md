# 预注册：s=5 的跳变是读出层的产物吗？（D3 探针）

2026-10-30。写于脚本运行之前。只做推理，训练只涉及读出层（逻辑回归 / 原型），不训练骨干。

## 1. 为什么做

D2（`PREREG_FEATURE_DRIFT.md` 的结果）显示：表征漂移 `E_feat` 在 s=2 就已为正，并随严重度平滑增长（0.005 → 0.020 → 0.075 → 0.150）；而准确率超加性直到 s=5 才出现（0.0 / +4.9 / +3.4 / +9.7 pp）。两者在严重度轴上**不是同一个形状**。

若跳变来自学习到的分类边界（表征缓慢漂移，某点越过边界），换一个更简单的读出规则应当改变曲线形状；若任何读出都保留跳变，则它在表征几何本身。

## 2. 度量

冻结基线骨干（`convnext_tiny_none_e40_s{seed}`，fold0，s17/s29）的 768 维描述子，L2 归一化。训练时不接触任何退化图像：

- `logreg`：多项逻辑回归（C=1）在 clean 训练特征上拟合；
- `prototype`：类质心余弦最近邻。

评测条件与 D2 相同（45 个）。准确率超加性沿用同一公式：

`E_acc(s) = [acc(clean) − acc(a+b,s)] − {[acc(clean) − acc(a,s)] + [acc(clean) − acc(b,s)]}`

## 3. 预测

| 编号 | 预测 | 判定 |
|---|---|---|
| P1 | 至少一种读出把 `E_acc(haze+glare, 5)` 从模型的 +9.7 pp 降到 **≤ +4.9 pp**（降幅 ≥50%），同时 clean 准确率损失 ≤1 pp | 主检验 |
| P2 | `prototype` 读出在 s=5 的绝对准确率不低于模型（frozen-readout 净空 ≥0，与 G2 的 +3.3 pp 同向） | 辅助 |
| P3 | 两种读出的 `E_acc` 在 s=2–4 都接近 0 | 形状一致性 |

## 4. 决策规则

- **P1 成立** → 跳变是读出层产物。下一步方法限定在读出/校准层（原型锚定、边界整流、温度校准），不碰输入与骨干。
- **P1 不成立** → 跳变在任何读出下都保留 → 表征几何本身在 s=5 进入单退化到不了的区域。下一步方法应为**覆盖该区域**（物理耦合的训练采样：雾提升亮度 → 眩光增益条件化）或**弃权/验证**机制，而非特征改造。
- 任一情况下读出的 clean 准确率不得低于模型 1 pp 以上，否则该读出只用于诊断，不作为方法基线。

## 5. 边界

读出只用 clean 训练特征，不模拟组合增强；因此若 logreg 在退化下更差，说明模型学到的退化不变性确实有用，不能读成"读出更好"。本探针只回答**曲线形状是否由读出决定**，不回答性能上限（G2 已单独处理）。

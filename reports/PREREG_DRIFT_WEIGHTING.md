# 预注册：逐图表征漂移加权训练（M2）

2026-10-30。写于训练之前。这是**方法候选**，不是探针；按 §4 的判据决定去留。

## 1. 已知与动机

- D2：逐图表征漂移 `d = 1 − cos(f_clean, f_aug)` 在 s=2 起就超加性、随严重度平滑增长；**逐图**漂移能以 AUC 0.779/0.823 定位失败，与 `E_acc` 的 Spearman ρ 为 0.850/0.795。
- D3：换读出层（logistic / 类原型）s=5 跳变不减反增 → 不是分类头产物。
- 专训上界：s=5 复合曝光 ×4 不能移动 s=5 准确率（≤5 pp，符号随种子翻转）→ s=5 是信息上限。
- 因此，若还有可做的，只剩**用逐图信号重新分配训练容量**；此前 7 个候选全部使用**条件级**信号（条件分组 DRO、课程、掩码、读出重拟合、采样配比），这是唯一未试的信号粒度。

s≤4 匹配复合 6 条件均值基线：**79.69**（s17）/ **77.10**（s29），clean 84.47 / 82.04。可争空间约 5 pp。

## 2. 方法

**信号（教师）**：冻结的同种子基线 `runs/fgsc23_civ8_fold0/convnext_tiny_none_e40_s{seed}/best.pt`，`eval()`、无梯度。对每个训练样本，取**同一几何增强**的两个视图——未退化视图与配方抽到的视图——经教师的 `features_of`（768 维池化描述子，L2 归一化后）的余弦距离：

```
d_i = 1 − cos( f_teacher(clean_i), f_teacher(aug_i) )      d_i ∈ [0, 2]
```

教师只提供标量 `d_i`，**不迁移任何权重**。干净样本 `aug ≡ clean`，故 `d_i = 0`。

**权重**：批内漂移百分位秩 `r_i ∈ [0,1]`，

```
w_i = exp( α · (r_i − 0.5) )
```

`α = +1` 为主臂（高漂移样本权重 1.65，低漂移 0.61）。用秩而非绝对值，是为了让权重只依赖**批内相对排序**，与严重度分布、批次构成解耦。

**损失**：`L = Σ w_i CE_i / Σ w_i`。其余一切不变：fold0、ConvNeXt-T ImageNet-1K、40 epoch、同优化器/调度/判优指标/几何增强/退化配方。运行名 `convnext_tiny_d1_e40_s{seed}`。

**方向对照（必跑）**：`α = −1`（低漂移样本加权），运行名 `convnext_tiny_d1inv_e40_s{seed}`。理由见 §3 的风险条目：漂移最大的样本恰恰集中在 s=5，而专训探针已证明那里信息被抹除；因此"加大高漂移样本权重"在 s=5 上是有理论前科的方向，必须同时检验反方向，否则得到零结果也无法区分"信号无用"与"方向选错"。

**代码等价性检查（先于正式训练）**：`α = 0` 时 `w_i ≡ 1`，损失退化为普通交叉熵，数据路径与基线 `ShipDataset` 必须逐次抽取一致。先用 `α = 0` 跑 3 epoch，与基线 `history.json` 前 3 epoch 的 `train_loss / val_macro_f1` 对齐（容差 1e-3）；不对齐则先修数据路径，不启动正式臂。

## 3. 主指标与判据

**主指标 `combo_low`**：`matched_haze+glare_{2,3,4}` 与 `matched_haze+cloud_{2,3,4}` 六条件的准确率均值（severity 2/4 用 `severity_curve_eval.EXTRA` 的同一批退化实例）。**只看 s≤4**。

| 编号 | 判据 | 阈值 |
|---|---|---|
| G1 | `combo_low` 增益（两种子均值） | ≥ **+1.5 pp** |
| G2 | 种子一致性 | 两个种子都 > 0 |
| G3 | 显著性：按 `source_group_id` 的配对 cluster bootstrap（2000 次，图像×条件池化）95% CI | s17 与 s29 **都排除 0** |
| G4 | clean 准确率损失 | **两个种子都 ≤ 1 pp** |
| G5 | 不设 s=5 判据 | s=5 只报告，不作卖点、不作准入条件 |

**通过** = G1∧G2∧G3∧G4。**通过后**才允许进入 3 折 × 2 种子的确认阶段，成本另计。

## 4. 决策规则（写死）

- **主臂通过** → 进入 3 折确认；确认阶段若 3 折中 ≥2 折为正且均值 ≥ +1.0 pp，才作为方法写入草稿。
- **主臂不通过、反向臂通过** → 结论是"漂移加权的方向应为负"，同样进入 3 折确认，但必须先在新预注册里说明方向翻转的理由（这是一个事后发现的方向，确认阶段必须独立）。
- **两臂都不通过** → 关闭"损失层重加权"整条路线。不再调 `α`、不再换秩的构造、不试 focal/curriculum 变体。理由：两种相反方向、两个种子、8 个 run 都不动，剩下的只是噪声拟合。
- **G4 单独失败**（性能涨但 clean 掉）→ 记为泄漏式增益，不算通过。

## 5. 已知风险与边界

1. **方向风险**（最高）：`d` 在 s=5 最大，而 s=5 已被证明信息受限。`α=+1` 可能把容量推向不可学样本。这正是同时跑 `α=−1` 的原因。
2. **循环性**：教师是同一数据、同一配方训练出的基线模型。`w_i` 只含一个标量，不迁移权重，但这仍使 M2 依赖"先有一个基线模型"。可迁移版本（用学生的 EMA 教师）本预注册不检验，若主臂通过，确认阶段必须补。
3. **计算**：每步多两次教师前向（约 3× 训练时间）。
4. **单折两种子、单骨干**。任何通过结论在 3 折确认前都只是准入证据。
5. **不是新架构**：M2 不改变模型、推理成本不变（教师只在训练期存在）。

# 预注册：严重度 2/4 组合退化补充评估

2026-10-30。**本文件在运行前写下**，任何结果出来后不修改其中的判据与预期。

## 1. 动机

现有评估的组合条件只有严重度 3 与 5。`COMPOUND_ANALYSIS.md` 得到的结论是"超加性只在严重度 5 出现"，但基于两个点，无法区分：

- **阈值型**：低于某个严重度时不出现超加性；
- **单调型**：超加性随严重度递增，只是在 3 时还小于噪声。

补两个中间点（2 和 4）可以把两档观察变成四点曲线。

## 2. 范围（严格限定）

| 项 | 取值 |
|---|---|
| 条件 | `matched_haze+glare_{2,4}`、`matched_haze+cloud_{2,4}`，共 4 个；另加 clean 作参照 |
| 域 | 只用 `matched`；`shifted` 不补（避免把问题从"严重度曲线"扩大成"域 × 严重度"网格），在论文中明确列为未覆盖 |
| 模型 | 只评基线臂 `convnext_tiny_none_e40`，3 折 × 2 种子 = 6 个 run；**已存在的 checkpoint，不训练** |
| 管线 | 与 `explore_eval.py` 完全一致：同一 `corrupt()`、同一 `corruption_seed(sample_id,"efmnet",kind,severity,domain)`、同一预处理 |
| 代码 | 不改 `degradations.py`；新增脚本只构造额外的条件条目，`corrupt()` 本身已支持 1..5 全部严重度 |
| 成本 | 6 run × 5 条件 × 206 图 ≈ 6200 次前向，约 10 分钟 |

**不做**：不新增模型、不改变退化配方、不重筛候选、不动 236 张测试图的定位（仍为"已用于探索性诊断"，不是盲测）。

## 3. 预注册指标

对每个严重度 s ∈ {2,3,4,5} 与每个组合对 P ∈ {haze+glare, haze+cloud}：

1. **D(s)**：组合下降（相对于 clean），单位 pp；
2. **M(s)**：同两类单退化在全部 5 个严重度上的最大下降；
3. **E(s)**：准确率空间的超加性 = D(s) − [drop_a(s) + drop_b(s)]，以 (fold, source_group_id) 为簇做 4000 次 bootstrap；
4. **N(s)**：组合错误中"任何单退化都没错过"的比例（同种子、逐样本）。

## 4. 预注册预期（在看 s=2/4 结果之前写下）

| 编号 | 预期 | 判定 |
|---|---|---|
| P1 | E(s) 随 s 非单调递减：E(2) ≤ E(3) ≤ E(4) ≤ E(5)（点估计，6 个 run 中至少 5 个满足） | 若不满足，记为"非单调"，不做修补 |
| P2 | E(2) 的 95% CI 包含 0 | 若排除零且为正，则超加性并非高严重度特有 |
| P3 | E(5) 的 CI 下界 > 2 pp（复现现有结论） | 若不复现，说明现有结论不稳 |
| P4 | N(s) 随 s 单调不减（按 4 个点的点估计） | 否则记为不确定 |

## 5. 结果如何影响论文（无论哪种结果）

- 若 P1–P4 成立：论文写"超加性随严重度增长、在最高严重度跨越阈值"，主图是四点曲线。这是最强的版本。
- 若出现 E(2) 或 E(4) 大且 CI 排零：论文改写为"超加性在整个严重度范围存在"，这**同样是结论**，不是失败，E2 的表述随之扩大。
- 若曲线非单调：如实写非单调，并把"阈值"改为"在测试的四点中，最大严重度出现最强超加性"。
- **任何结果都不改变"进入论文写作"的决定**（已由项目负责人预先确定）。

## 6. 多重比较

4 个严重度 × 2 个组合对 = 8 个 E 值，另加 8 个 N 值。E 的 CI 按簇 bootstrap 给出，同时报告 BH 校正后的 q 值（8 个检验）；N 只作描述。

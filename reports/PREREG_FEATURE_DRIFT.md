# 预注册：超出加性的损失发生在表征还是决策边界？（D2 探针）

2026-10-30。写于任何前向计算之前。只做推理，不训练。

## 1. 问题

`COMPOUND_ANALYSIS.md` / `SEVERITY_CURVE.md` 已确立：haze+glare 在 s=5 的准确率下降比加性预期多 **+11.3 pp**，且 41.5% 的错误是单退化不产生的。这告诉我们**行为**，不告诉我们**位置**。

要在两种完全不同的方法投资之间做选择，必须先分辨：

- **表征假设**：复合退化把图像压进了一个单退化到不了的嵌入区域（信息在 backbone 输出处就已经缺失/错位）。→ 方法应作用于特征提取（架构、归一化、证据加权）。
- **决策假设**：表征漂移是可加的，但可分性/边界在复合条件下被破坏（类间距离压缩、边界偏移）。→ 方法应作用于读出层（原型校准、边界整流、度量化）。

## 2. 度量（先定义，后使用）

对基线模型 `convnext_tiny_none_e40_s{seed}`（fold0，seeds 17/29）：

- `f(x)`：`features_of` 的 768 维最终描述子（`MethodModel.features_of`，已在 m1 中使用）。
- **表征漂移** `D(c) = 1 − mean_i cos(f_clean(x_i), f_c(x_i))`，逐图计算后取均值。分子：1 减余弦相似度；分母：该条件全部 206 张验证图。
- **加性预期** `A(s) = D(a,s) + D(b,s)`，a、b 为两个组成退化，同一模型、同一图像、同一严重度。
- **表征超加性** `E_feat(s) = D(a+b,s) − A(s)`，单位：余弦距离。

准确率侧的同构量：

- `E_acc(s) = [acc(clean) − acc(a+b,s)] − {[acc(clean) − acc(a,s)] + [acc(clean) − acc(b,s)]}`（与草稿 §4.3 一致）。

两个量的单位不同（余弦距离 / 准确率 pp），只比较**符号与条件排序**，不比较数值大小。

## 3. 预测

| 编号 | 预测 | 判定 |
|---|---|---|
| P1 | `E_feat(haze+glare, 5) > 0`，聚类 bootstrap 95% CI 排除 0 | 主检验 |
| P2 | `E_feat(·, s)` 在 s=2,3,4 上 CI 覆盖 0（两个复合） | 与准确率侧的"仅 s=5"一致 |
| P3 | 23 个 matched 条件上 `E_feat` 与 `E_acc` 的 Spearman ρ ≥ 0.6 | 表征级信号能解释条件级差异 |
| P4 | 新错误（单退化全对的图）上 `D(haze+glare,5)` 高于其余图，AUC ≥ 0.65 | 表征漂移能逐图定位失败 |

推断口径：按 `source_group_id` 聚类 bootstrap 2000 次；同一图的种子放在同簇。

## 4. 决策规则（写死，不事后改）

- **P1 成立** → 投资表征侧：先测"漂移方向"是否可判别（新错误图的漂移是否朝某一类原型），再设计作用于表征的方法。
- **P1 不成立**（CI 覆盖 0）→ 表征漂移是可加的，超加性来自读出/决策几何。后续候选限定在读出层，禁止再试输入/表征模块（含多尺度、去噪、归一化、掩码）。
- **P1 成立但 P4 不成立** → 表征在条件层面解释了差异，但不能逐图定位；方法必须依赖条件级信号（例如训练时的耦合采样），不能依赖逐图检测器。

任一情况下都不以单一探针结果宣称机制；探针只用于排除投资方向。

## 0. 起点

G2 的结论把一整类方法从预算里删掉了：

> 冻结表征上，任何只改分类头的方法（校准、原型、margin、温度）上限 ≈ +3.3 pp，且净空在 12 个组合检验上 BH 后 0/12 显著。

因此后续投入只放在三处：**表征、训练分布、输入**。决策层不再投入 GPU。

预算实测：`runs/**/complete.json` 记录的 57 次训练合计 **2.9 GPU-h**；EFM-Net 外部训练按 checkpoint 间隔（100 epoch / 14 min）估算 ≈ 1.6 h；43 条件评估以 CPU 生成退化为主，GPU 部分 < 0.5 h。**合计约 5–6 h，72 h 预算剩余约 65 h。** 本计划用量 15–18 h，留足复现与返工余量。

## 1. 指标与判据（先定，不改）

| 项 | 取值 |
|---|---|
| 主指标 | 8 个 `combo_both` 条件上的平均 Δ（pp，相对同种子 combo 基线） |
| 次指标 | single_matched / single_shifted / clean 上的 Δ；逐类召回 |
| 稳定提升判据 | 均值 ≥ **+1.5 pp** 且 ≥ **2/3** 种子为正 且 clean ≥ **−1.0 pp** 且其余层 ≥ **−2.0 pp** 且配对分组 bootstrap（按 `source_group_id`）95% CI 下界 **> 0** |
| 成本上限 | 参数量 ≤ +10%，单图 FLOPs ≤ +15%，推理延迟 ≤ +15%；必须报「每百分点增益的成本增量」 |
| 比较基线 | `*_aug_*`（普通增强）与 `*_combo_*`（组合增强）**两者都要报** |
| 数据纪律 | 筛选只用 train；val 只用于阶段确认；test 236 只在方法冻结后跑 **一次** |
| 报告纪律 | 不报最佳单条件、不做事后挑选；BH 多重比较校正 |

### S1 噪声地板（2026-10-30 实测，已完成）

同一配置（ConvNeXt-T + combo 增强、24 epoch）在 3 折 × 3 种子（17/29/43）上的 combo 条件均值：

| fold | s17 | s29 | s43 |
|---|---:|---:|---:|
| fold0 | 70.0 | 67.8 | 73.3 |
| fold1 | 78.0 | 78.6 | 77.2 |
| fold2 | 75.6 | 74.9 | 76.1 |

同折换种子的 Δ：sd **1.9 pp**，极差 5.5 pp（n=6）。

**结论**：单种子筛选的分辨力低于 +1.5 pp 判据——单种子会直接制造假信号，正是本轮要避免的赢家诅咒。因此 S1 改为 **2 种子 × 3 折**（6 个配对测量，均值的 SE ≈ 0.8 pp），单种子只用于排查崩溃。这是对原计划 §3 的修正，理由来自实测而非猜测。

**关于 S1 的妥协（需确认）**：训练集只有 618 张，若用 val 做筛选就等于把确认集烧掉。因此筛选用 train 内 3 折（每折 ≈412/206），并缩短训练轮数。代价是筛选数值不能当最终结论；它只用于**排序**。每折 206 张上 combo 条件的 SE ≈ 3.5 pp，3 折合计的有效精度约 2 pp，足以区分 ≥3 pp 的差异，不足以分辨 1 pp 级别的优劣——这正是把它定位成「排序」而不是「测量」的理由。

**S1 的淘汰规则**：任一新候选若在三折上相对 combo 基线的平均 Δ 为负，或训练不稳定（loss 非有限 / 崩溃），直接淘汰，不进入 S2。

## 4. T1 的实现要点（唯一需要新机制设计的候选）

- 取同一张 train 图，生成两路：单退化 `d_i`、组合 `d_i + d_j`（沿用冻结的 `degradations.py` 与同一套种子逻辑，不改参数）。
- 约束：`KL( p(y|x_single) ‖ p(y|x_combo) )` 或对称一致性损失，权重 λ 需在 {0.1, 0.5, 1.0} 内做**一次**选择（在 S1 阶段定，之后冻结）。
- 假设：模型若被迫在组合退化下保持与单退化一致的判别分布，就必须学到退化之间的交互结构，而不仅是各自独立的鲁棒性——这正好对应实测的超加性。
- 证伪：若 T1 在 S2 达不到稳定提升判据，则「超加性不可由一致性约束缓解」成立，该方向同样进负结果章节。

## 5. 提炼规则（替代「取公共点」）

1. S2 结束后，取通过判据的候选；若 ≥2 个，进入 S3。
2. S3 只做 **2×2**，测交互项：
   `interaction = Δ(A+B) − Δ(A) − Δ(B) + Δ(none)`。
3. 判定：
   - `interaction > +0.5 pp` 且 CI 不含零 → 两个因子存在协同，可组合成一个模块，且**协同本身是贡献**。
   - 否则 → 只报告单因子，**不做拼接**。
4. 最终模型必须是「一个可解释的机制」，不是若干 trick 的堆叠。若最终只能靠堆叠获得增益，则该增益不构成创新，不作为论文主张。

## 6. 停止规则与失败形态

- S1 后若无候选的三折平均 Δ ≥ +1.5 pp → **停止**，不进入 S2，剩余预算不动。
- S2 后若无候选通过稳定提升判据 → **停止**，写负结果。
- 若全部落 ±1 pp 内，诚实的结论是：组合退化在这批骨干上是硬上限。论文贡献转为**基准 + 超加性现象 + 两组负结果（G1 跨骨干、G2 决策层）**。这比一个 +0.8 pp 的拼接模块更有价值。

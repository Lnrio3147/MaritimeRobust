# 统一实验结论

2026-10-30。方法搜索已按预注册停止规则结束。本文件把**实证结论**与**解释性假设**分开陈述，并写明每条结论的边界。

停止状态：不做 R2，不开第三批，不为挽救失败候选调参。

## 0. 一句话总结

在固定数据（FGSC-23 民用 8 类，618 训练 / 157 验证）、固定训练配方（ConvNeXt-T + 组合增强 + 40 epoch）下，退化复合使强基线显著下降且带超加性；七个试图改善它的候选与一个更强的初始化对照，均未显示稳定的相对增益。**这证明了这套协议下"单点改动难以超越强组合增强基线"，不证明组合退化存在性能上限。**

## 1. 实证结论

### E1. 组合退化造成大幅且非均匀的性能下降

| 证据 | 数值 |
|---|---|
| research/civilian 组合增强基线，clean → 8 个组合条件均值 | 88.36 ± 0.55 → 77.61 ± 2.08 macro-F1 |
| 最差条件 | 58.06 ± 5.40 |
| 跨 4 个骨干家族，Δ ≤ −5 pp 且 CI 不跨零的条件 | 9 个（`matched_glare_5` 4/4 家族 −10.6…−14.6；`matched_haze+glare_5` 4/4 家族 −26.1…−43.3） |

边界：只覆盖 FGSC-23 的合成退化协议与这四个骨干家族。

### E2. 组合退化存在超加性（相对单退化的加性预期）

| 证据 | 数值 |
|---|---|
| 雾+眩光相对加性预期的额外 margin 损失 | −0.152 … −0.032 |
| 雾+云 | −0.144 … +0.009 |

边界：margin 层面的描述性统计，跨骨干成立；不解释成因。

### E2b. s=5 超加性经独立物理渲染复现，但「s≤4 可加」不成立

| 渲染 | E(5) s17 / s29 | E(4) s17 / s29 |
|---|---:|---:|
| 现行（冻结基线） | 9.7 / 12.6 | ≤4 的逐 run 最大值 4.9 / 1.9 |
| 物理（冻结基线，未重训） | +14.6 / +21.8 | +9.7 / +4.4 |
| 物理（同渲染重训 40 epoch） | +10.2 / +16.0 | +8.3 / +7.8 |

物理渲染器：Koschmieder 深度透射、天空中位 airlight、耀光镜面瓣 + 饱和 blooming；严重度按平均透射与饱和像素比例对齐（Δ ≤ 0.008 / 3e-8）。

边界：**s=5 的额外量不是渲染器伪影**（四个 run 全部 ≥5 pp）；但**出现点依赖渲染**——物理渲染下从 s=4 起就有 8–10 pp 的超加性，因此正文「阈值型、跨越点在 4|5 之间」只能作为现行渲染器下的描述，不能作为退化交互的性质。只测 matched 域 `haze+glare`，cloud 未物理化，fold0、单骨干。详见 `reports/PHYSICAL_RENDERER.md`。

### E3. 冻结线性读出的净空很小（G2）

| 量 | 值 | CI |
|---|---|---|
| H = P2 − model | +3.3 pp | [1.0, 5.6] |
| S = P2 − P1 | +7.7 pp | [4.7, 10.8] |
| T = P1 − model | −4.5 pp | [−6.8, −2.1] |
| BH 后显著的组合检验 | 0 / 12 | — |

边界：只对线性读出成立；不能区分「表征无信息」与「表征需要非线性边界」。这条边界是 G2 结案时的明确记录。

### E4. 受限训练预算会制造假增益（方法筛选的元结论）

| 证据 | 24 epoch | 40 epoch |
|---|---|---|
| T1 相对基线（8 组合条件） | +1.66 pp [0.63, 2.68] | −0.18 pp [−1.13, 0.76] |
| 基线自身 val macro-F1 | 84.5 | 85.7 |

结论：短训练筛出的正收益，在充分训练后消失。这是一条可复现的方法学观察，直接约束任何「小预算快速筛选」的做法。

### E5. 八个候选、一次方向对照、一个初始化对照和一次非预注册机制检验均无稳定增益

| 候选 | 层 | 均值 Δ | 95% CI | 判据 |
|---|---|---:|---|---|
| T1 组合一致性 | 训练 | +1.66（24ep）→ −0.18（40ep） | [−1.13, 0.76] | 未维持 |
| I1 条件化归一化 | 输入 | +0.94 | [−0.09, 1.98] | 未达标 |
| R3 特征去噪 | 表征 | −0.69 | [−1.76, 0.35] | 无正证据 |
| R1 多尺度融合 | 表征 | −1.10 | [−2.23, 0.05] | CI 跨零 |
| I2 Retinex | 输入 | −2.56 | [−3.86, −1.22] | 显著为负 |
| T2 退化组 DRO | 训练 | −5.04 | [−6.52, −3.54] | 显著为负 |
| T3 课程式组合 | 训练 | −8.76 | [−10.14, −7.40] | 显著为负 |
| T4 22K 初始化 | 初始化 | −0.71 | [−2.07, 0.52] | 未证明优势（clean +0.73） |
| M1 截断像素掩码（非预注册，机制检验） | 输入 + 读出 | +0.61（s17）/ +0.97（s29） | 逐图 McNemar p=0.43 / 0.27 | 无增益；单退化反而变差 |
| M2 逐图漂移加权 α=+1 | 训练（逐图） | −1.29（s17）/ +0.16（s29） | s17 [−4.57, 1.96] | 未达标；clean −1.46 |
| M2 逐图漂移加权 α=−1（预注册方向对照） | 训练（逐图） | +0.65（s17）/ +2.99（s29） | s17 [−0.97, 2.32]，s29 [+0.56, 5.61] | s29 显著但增益宽谱（clean +1.94、单退化 +1.24），非组合特异；未过准入 |

边界：R2（FFC）未执行，不在本表覆盖范围内；各候选只测试了「单独开启」一种配置，没有测试组合。M2 的详细判据见 `M2_DRIFT_WEIGHTING.md`，预注册 `PREREG_DRIFT_WEIGHTING.md`。

### E6. clean 性能与组合退化性能不同向

| 证据 | clean | 组合 |
|---|---:|---:|
| T3 课程 | 85.1（候选中最高的 clean） | 67.3（候选中最差） |
| T4 22K 初始化 | +0.73 pp | −0.71 pp |

结论：clean 准确率不能单独代表复合退化性能。这是可直接陈述的观察，成因未验证。

### E7. 改动倾向于破坏多于修复

| 方法 | 修复 | 破坏 | 净 |
|---|---:|---:|---:|
| R1 | 620 | 728 | −108 |
| I2 | 639 | 904 | −265 |
| T2 | 608 | 1103 | −495 |
| T3 | 547 | 1415 | −868 |

统计口径：计数来自 6 个 (折, 种子) × 8 条件 × 206 图，**不是独立样本**，只用于描述方向，不用于显著性推断。

## 2. 解释性假设（未验证，不作为结论）

| 假设 | 缺哪次消融 |
|---|---|
| 课程在严重度 5 的组合上训练不足 | 训练晚期各严重度的实际覆盖统计；课程只作用于「单→组合」的对照 |
| DRO 把权重集中到最难组、牺牲平均 | 最终 q 分布；固定组重加权对照 |
| Retinex 抹掉了与退化强度相关的判别信息 | 逐图标准化 vs 固定变换；仅训练期 vs 训练+测试都应用 |
| 预训练质量对组合退化不重要 | 未验证——只比较了两个具体权重 |
| 组合退化不可由单点模块缓解 | 未验证——R2 未做，未测试多因子组合 |

## 3. 明确未覆盖的范围

1. 更深的骨干、更强的训练配方、更大数据规模；
2. 频域方法（R2 未执行）；
3. 多因子组合与交互（S3 未启动）；
4. 非线性读出的上限（G2 只测线性）；
5. 真实退化条件下的因果效应（只有观察性分层，重度样本 n≤2）。

## 4. 复现口径

- 所有配对测量：同折、同种子、同退化实例（`corruption_seed(sample_id, "efmnet", …)`），逐图配对。
- 所有区间：按 `source_group_id` 聚类、种子成簇的 bootstrap。
- 所有筛选：train 内 3 折，val 不参与；预注册与实际执行的差异记录在 `PROBE_PREREGISTRATION.md` §9。
- 累计训练 128 个 run，约 3.3 GPU-h。M1 的检验细节见 `M1_KILL_TEST.md`，不改变 §1 的任何实证结论。

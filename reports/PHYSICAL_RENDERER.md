# 物理渲染复核：s=5 超加性不是渲染器伪影，但"4|5 阈值"是

2026-10-30。预注册 `PREREG_PHYSICAL_RENDERER.md`（写于实现与评测前）。两阶段：Stage 1 用冻结基线配独立渲染器，Stage 2 在独立渲染器上重训。无方法贡献，纯有效性检验。

## 1. 做了什么

新模块 `src/maritime_robust/physical.py`，不改 `degradations.py`。替换现行渲染器的两处非物理近似：

| | 现行渲染器 | 物理渲染器 |
|---|---|---|
| haze 透射 | 近似均匀（±0.18 抖动），无深度 | `t = exp(−β·d(y))`，地平面深度先验，逐图二分求 β |
| airlight | 随机近白 0.85–0.98 | 天空区（地平线以上）中位色 |
| glare | 加性高斯光晕，直接 clip | 水面镜面耀光瓣 + 饱和掩码高斯扩散（blooming）回注 |
| 严重度定义 | 手设常数 | haze 按**平均透射**、glare/复合按**饱和像素比例**，对齐到现行渲染器在同图上的实测值 |

对齐误差（P3）：饱和 Δ ≤ 0.0083，透射 Δ ≤ 2.6e-8，逐严重度全部通过。因此比较的是"同样的像素统计、不同的物理结构"。

Stage 1 的模型是冻结基线 `convnext_tiny_none_e40_s{17,29}`（fold0，未见过物理渲染）。Stage 2 用同一模型结构、同一配方 draw（逐样本核对 kind 不一致 0）在物理渲染下重训 40 epoch，`convnext_tiny_p1_e40_s{17,29}`。

## 3. Stage 2：同渲染重训

| run | clean | E(2) | E(3) | E(4) | E(5) |
|---|---:|---:|---:|---:|---:|
| p1 s17 | 83.98 | +1.46 | −2.91 | +8.25 | **+10.19** |
| p1 s29 | 82.52 | +0.97 | +4.37 | +7.77 | **+16.02** |

clean 准确率与基线相差 −0.49 / +0.48 pp，训练分布已匹配，绝对数值可与现行渲染的 9.7 / 12.6 pp 直接比较。

## 4. 判定

1. **P1 在四个 run 上全部成立**：独立渲染下 E(5) = 10.2 / 16.0 pp（重训后），与现行渲染的 9.7 / 12.6 pp 同一量级。**s=5 超加性不是这套渲染器把亮度推到 clipping 的产物。**预注册决策规则中"现象依赖渲染实现"的分支**不成立**，这一条不得写。
2. **P2 在四个 run 上全部不成立，且方向一致**：物理渲染下超加性从 **s=4** 就出现（7.8–9.7 pp），而不是 s=5 才出现。因此正文"s≤4 可加、跳变位于 4 与 5 之间"是**现行渲染器**的性质，不是复合退化的性质。主张必须降级为"超加性随严重度上升、在最高严重度最大"，不能保留"阈值型"这一表述。
3. **P4 证据弱**：深度结构只在 s29 的 s=5 上有可测作用（+6.3 pp），s17 同条件只有 +1.9 pp，s=3 两个种子都是反向。深度先验不是现象的主要来源，但也不能排除其在最强复合下的贡献。
4. 物理渲染器训练出的模型对同一渲染下的复合退化更鲁棒（s=5 下降 27.7 / 33.0 pp 对比冻结基线的 37.9 / 41.7 pp），与"配方覆盖训练分布即有效"的既有结论一致，不构成新发现。

## 5. 对正文的影响

- 保留：§4–§5 中 E(5) ≈ 11 pp、41.5% 新增错误、以及"复合退化在最高严重度上非线性叠加"的结论。
- 收回："超加性只在最高严重度出现""跨越点位于 4 与 5 之间"。物理渲染下从 s=4 起出现，跨越点位置依赖渲染实现。
- §7.4 的单渲染限制改为"两种独立渲染实现下 E(5) 均成立；低严重度的可加区间不稳健"。这不是降级到"有第二套渲染"，而是**部分主张被收窄**。

## 6. 边界

1. 只测 `matched` 域、`haze+glare`；`haze+cloud` 饱和为 0、超加性弱，未重渲染。
2. cloud 未物理化（仍是原 alpha 合成）；`haze+cloud` 的训练视图是物理 haze 叠原 cloud。
3. 地平线是启发式（水平梯度能量最大行），天空区可能误判。
4. 严重度按可观测量对齐，等于把"饱和水平"钉死；本实验回答的是"同样饱和水平下空间结构是否重要"，不是"饱和是否为原因"。
5. 单折（fold0）、两种子、单骨干（ConvNeXt-T）。
6. Stage 2 只在物理渲染条件下评测，未在现行渲染条件下复评，因此不能回答"物理训练是否迁移回原渲染"。

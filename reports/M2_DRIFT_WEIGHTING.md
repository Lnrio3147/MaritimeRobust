# M2：逐图表征漂移加权训练——两个方向都未通过准入

2026-10-30。预注册 `PREREG_DRIFT_WEIGHTING.md`（写于训练前）。fold0、两种子、ConvNeXt-T。

## 1. 做法

冻结的同种子基线模型做教师，对每个训练样本取**同一几何**的两个视图（未退化 / 配方抽到的退化），逐图漂移

```
d_i = 1 − cos( f_teacher(clean_i), f_teacher(aug_i) )
```

按批内百分位秩 `r_i` 加权：`w_i = exp(α (r_i − 0.5))`，损失 `Σ w_i CE_i / Σ w_i`。教师只给标量，不迁移权重。

两个方向都跑：`d1`（α=+1，高漂移加权）与预注册的方向对照 `d1inv`（α=−1，低漂移加权）。4 个 run，全部 40 epoch，其余配置与基线逐项相同。

## 2. 数据路径等价性（先于正式臂）

`DriftDataset` 与基线 `ShipDataset` 逐样本比对：4 个 epoch（0/1/2/7）× 412 个训练样本，输入张量与标签**零差异**；α=0 时损失退化为普通交叉熵。因此两臂的差异只来自权重，不来自数据。

（α=0 的 3-epoch 试跑与基线 history 的 val 数不符，原因是 3 vs 40 epoch 的余弦调度不同 + GPU 非确定性；样本级比对才是等价性证据，已写入此处。）

## 5. 诊断：反方向的增益是宽谱的，不是组合退化特异的

`d1inv` s29 满足 G1/G2/G4，只有 s17 的 CI 跨零。但把它的增益拆开看，形状不符合"修复复合交互"：

- s29 同时把 34 个**单退化**提高 +1.24 pp、把 clean 提高 +1.94 pp、把 s=5 组合提高 +2.18 pp。八个匹配组合条件里 s29 有七个为正（+0.97…+5.34 pp）。
- s17 上同一配方只有 +0.65 pp，clean 反向 −0.49 pp。

一个只在 s=5 的复合交互上有作用的机制，不会同时抬高 clean 与单退化。这个形状更像是**训练方差的正则化**：压低高漂移样本的权重等于削弱最难/最噪样本的影响，降低了跨种子的方差——代价是收益不稳定（+0.65 对 +2.99，差 4.6 倍），且与"复合退化交互"这个目标没有机制联系。

因此即使忽略 G3 的失败，也**不能**把它写成复合退化的方法：它没有定向性。

## 6. 结论

1. 逐图信号（D2 的漂移）作为**损失权重**不产生可复现的定向增益。α=+1 有害（clean −1.46 pp），α=−1 的收益宽谱且种子不稳。
2. 至此第三条路线关闭：条件级重加权/课程（T2/T3）→ 采样配比（专训）→ **逐图级重加权（M2）**。三者的共同点是都在**重新分配训练容量**；专训探针已证明容量分配不是瓶颈，M2 在两个粒度上再次确认。
3. 唯一保留的正向线索是"漂移是好的**诊断**量"（AUC 0.78–0.82），而它**不是**好的**训练信号**。两者不矛盾：能预测失败的量不等于能用来修复失败。

## 7. 边界

- 单折、两种子、单骨干、单一权重族（秩 + 指数）。预注册已声明不做族外转向，故 focal / 逆概率 / 掩码类变体同属关闭范围。
- 教师是同一数据同一配方训练出的基线，存在循环性；可迁移版本（EMA 教师）未检验，但本预注册的结论不依赖它——两个方向都不动，说明问题不在教师的选择上。
- 推理成本不变：教师只在训练期存在。
- `d1inv` s29 的 +2.99 pp 是一个**观察**，不是**结论**。若要追它，必须在新预注册里把它作为"训练正则化"而非"复合退化方法"来检验，并且用 3 折 × 2 种子独立确认。

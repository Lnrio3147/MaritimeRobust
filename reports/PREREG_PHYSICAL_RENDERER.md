# 预注册：超加性是退化物理的性质，还是这套渲染器的产物？

2026-10-30。写于实现与评测之前。**Stage 1 不训练任何模型**。

## 1. 要攻击的弱点

全文的核心数值（s=5 处 E ≈ 11.3 pp、41.5% 新增错误、(4,5) 交叉）都建立在**一套**渲染实现上：

- haze：`I = J·t + A(1−t)`，`t` 近似均匀（±0.18 空间抖动），**无深度依赖**，airlight 随机取 0.85–0.98 近白；
- glare：加性高斯光晕 `gain·exp(−r²/2σ²)`，无镜头 PSF、无饱和溢出（blooming）；
- cloud：alpha 合成的白色圆形区域。

这些形式**部分的**物理，但不是物理渲染。审稿人最合理的一枪是：64% 饱和像素是这套渲染器把亮度推到 clipping 的产物，换个渲染方式现象就没了——而论文却把它讲成退化交互的性质。

## 2. 做法（Stage 1）

新模块 `src/maritime_robust/physical.py`，**不改** `degradations.py`（与已有 run 哈希绑定）。

以下三处替换为非平凡物理机制，其余（评估流程、种子、图像管线）完全不变：

1. **深度先验**：海面地平面。逐图估计地平线（上 70% 内水平梯度能量最大行），地平线以下按行给出归一化深度 `d(y) ∈ [0,1]`，以上为远（`d=1`）。
2. **haze（Koschmieder）**：`t = exp(−β·d(y))`，即**透射随深度衰减**；airlight `A` 取天空区（地平线以上）的中位色，不再随机取近白。`β` 逐图二分求解，使全图平均透射等于现行配方的 `haze_transmission[severity]`——**按透射对齐严重度**。
3. **glare（太阳耀光 + 传感器）**：
   - 耀光位置由太阳高度角决定的水面镜面反射点（地平线下方），各向异性镜面瓣；
   - **传感器响应**：饱和掩码经高斯扩散（blooming）后回注，再 clip——现行渲染器缺的正是这一步；
   - 逐图二分求解曝光增益，使**饱和像素比例等于现行渲染器同严重度的实测值**（逐个条件在 fold0 的 206 张验证图上测出）。

**严重度由此按两个可观测量对齐**：haze 按平均透射，glare 按饱和比例。这样比较的才是"同样的像素统计、不同的物理结构"。

范围：只做 `matched` 域、`haze+glare` 这一条（现象主要在这里：饱和 60%、下降 25.7 pp）。`haze+cloud` 的饱和为 0、超加性弱（+0.6/+1.0 pp），本轮不重渲染，如实说明。

**被测模型**：现有基线 `convnext_tiny_none_e40_s{17,29}`（fold0），不重训、不微调。

**条件（15 个）**：clean；`physical_haze_{2,3,4,5}`；`physical_glare_{2,3,4,5}`；`physical_haze+glare_{2,3,4,5}`；外加深度消融 `physical_haze_uniform_{3,5}`（透射均匀、其余同 2）。

**指标**：与正文同式，加性基线仍用**同一个渲染器**下的单退化条件计算：

```
E_P(s) = [acc_P(clean) − acc_P(haze+glare, s)] − {[acc_P(clean) − acc_P(haze, s)] + [acc_P(clean) − acc_P(glare, s)]}
```

## 3. 预测与判据

| 编号 | 预测 | 判定 |
|---|---|---|
| P1 | `E_P(5) ≥ 5 pp`：物理渲染下悬崖仍在（对照：现行渲染 9.7 / 12.6 pp） | 现象不是渲染器伪影 |
| P2 | `E_P(2..4)` 在 ±3 pp 内 | 低严重度的可加性同样保留 |
| P3 | 严重度对齐有效：逐严重度平均饱和比例与目标差 ≤ 0.05，平均透射与目标差 ≤ 0.03 | 对齐成功，否则结果不可解释 |
| P4 | 深度消融：`E_P` 用均匀透射时与用深度透射时相差 ≥ 3 pp | 深度结构有作用（次要，不影响主判据） |

## 4. 决策规则（写死）

- **P1 ∧ P2 ∧ P3 成立** → 结论：超加性对渲染实现稳健。正文可写"两种独立渲染实现下现象一致"，并把 §7.4 的"单渲染"限制降级。
- **P1 不成立** → **不得**立即下结论。先做 Stage 2：把物理渲染器写进训练增强配方（`configs/physical_augmentation.json`），重训 fold0 × s17/s29，再测 E_P。只有 Stage 2 也没有超加性，才可以写"现象依赖渲染实现"并把 §4–§5 的主张收窄。
  理由：Stage 1 的模型从未见过物理渲染器，绝对准确率必然下降，E 可能被域偏移掩盖。这条不可省。
- **P3 不成立** → 对齐失败，结果作废，重做对齐；不得解释 P1。
- 无论结果如何，都**不**改渲染器参数去追 P1。一次定稿。

## 5. 边界与已知风险

1. **Stage 1 有域偏移**：模型未在物理渲染下训练，E 的绝对值不可与现行渲染直接比较，只能比较结构（是否存在悬崖）。这是 Stage 2 存在的原因。
2. **地平线估计是启发式**，天空区可能被误判；P3 的对齐检查会暴露一部分失败。
3. **对齐本身可能过强**：把饱和比例钉死等于把"现象的原因"钉死。因此本实验回答的是"在同样饱和水平下，结构是否重要"，不是"饱和是否是原因"。若 E_P(5) 崩溃而饱和对齐成功，正确结论是"现象依赖饱和的**空间组织**"，不是"现象是伪影"。
4. 单折、两种子、单骨干；只测 `matched`；只替换 haze 与 glare，cloud 未物理化。
5. 这是**有效性**检验，不产生任何方法或精度改进。

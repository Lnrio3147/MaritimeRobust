# 预注册：s=5 复合区域到底还剩多少信息？（专训上界探针）

2026-10-30。写于运行之前。只训练 ConvNeXt-T 的采样分布对照，不是方法候选。

## 1. 已知

- D2：表征漂移在 s=2 起就超加性，随严重度平滑增长；准确率只在 s=5 跳变。
- D3：换成逻辑回归或类原型读出，s=5 的跳变不减反增（+10.7/+14.6 对模型 +9.7），绝对准确率也更低。→ 跳变不是分类头造成的。
- 训练配方中 s=5 复合已出现约 12.5% 的样本（`combined_severities: [3, 5]`，退化批次中 50% 为复合），因此"完全没见过"不成立。

两种剩余解释：

1. **信息仍在、分配不足**：s=5 复合样本相对单退化仍少，且与干净样本、单退化共享全部容量。若把全部退化预算给 s=5 复合，性能应明显上升。
2. **信息被破坏**：60% 像素饱和 + 低对比（`SATURATION_PROBE.md`）已抹掉类别证据，任何模型都到不了更高。

## 2. 做法

`configs/specialist_s5.json`：clean 0.5，其余全部为 s=5 复合（haze+glare / haze+cloud 各半）。其余完全一致：fold0、ConvNeXt-T ImageNet-1K、40 epoch、AdamW/SGD 同配置、种子 17/29。运行名 `convnext_tiny_none_e40_s5spec_s{seed}`。

评测：同一 43 条件、同一退化实例、同一 val 206 张，`scripts/explore_eval.py`。

## 3. 主指标与预测

**主指标**：`matched_haze+glare_5` 与 `matched_haze+cloud_5` 的准确率。

| 编号 | 预测 | 判定 |
|---|---|---|
| P1 | 专训模型的 s=5 复合准确率比基线（55.3 s17 / 53.9 s29）高 **≥10 pp** | 信息仍在，问题在分配 → 可做方法 |
| P2 | 专训模型的 s=5 复合准确率与基线差 **≤5 pp** | 信息受限 → 不做容量/采样类方法 |
| P3 | 专训模型的 clean 准确率下降 ≤5 pp | 分配不是零和的辅助证据 |

## 4. 决策规则

- **P1 成立** → 下一阶段做**训练分布设计**（把 s=5 复合作为独立难度层，配比/课程按严重度分层），并以基线配方为对照；这是方法候选，需要预注册筛选判据（组合条件均值 ≥ +1.5 pp、≥2/3 折为正、clean 损失 ≤1 pp、配对 bootstrap 排除零）。
- **P2 成立** → 停止采样/容量方向。剩余可做的是**输入侧恢复**（对已饱和区域做估计而非掩码）或**拒识/验证**；两者都以这个上界为天花板。
- 若 P1、P3 同时成立而单退化性能大幅下降，则说明 s=5 是一个需要独立专家/分层模型的场景，方法应是**分层路由**而不是单一模型。

## 5. 边界

- 单折两种子；专训模型不训练单退化，因此其在单退化上的数字**不能**作为方法性能，只用于核对"任务未被破坏"。
- 本探针只给上界，不构成方法贡献；即使 P1 成立，也需在完整配方下重新验证。

## 2. 预注册判据逐条对照

| 编号 | 预注册内容 | 结果 | 判定 |
|---|---|---|---|
| P1 | E(s) 单调不减，6 个 run 中 ≥5 个满足 | 合并点估计单调；**逐 run 只有 2/6 单调** | **不成立** |
| P2 | E(2) 的 95% CI 包含 0 | [−1.45, +1.38] | 成立 |
| P3 | E(5) 的 CI 下界 > 2 pp | [+7.22, +15.22] | 成立 |
| P4 | N(s) 单调不减 | glare 3.8 → 6.6 → 19.1 → 41.5；cloud 1.0 → 5.5 → 7.2 → 22.9 | 成立 |

**P1 不成立，如实记录，不做修补。** 逐 run 的 E 值噪声（±3 pp 量级）大于 s=2…4 之间的差异，因此"随严重度平滑增长"这个说法没有证据支持。

## 3. 数据真正支持的表述

把 P1 的失败与其余三条放在一起，得到的是一个**比预注册更窄、但更硬**的结论：

1. **s=2 到 s=4 之间，超加性在统计上与 0 无异**（六个 run 中，三个 E 的 CI 全部包含 0；点估计在 −2.4 到 +4.9 之间波动，始终低于 5 pp）。
2. **s=5 与 s≤4 之间存在跳变**：在**全部 6 个 run** 中，E(5) 都大于该 run 的任一 E(s≤4)（9.7/12.6/15.5/12.6/9.7/7.8 对比各自最大 4.9/1.9/4.4/1.0/1.9/−1.0）。
3. 因此正确的表述是**"阈值型"**而不是"单调型"：**超加性只在最高严重度出现，跨越点位于 4 与 5 之间**；由于没有 s=4.5，无法进一步定位。
4. 同一模式在三种独立量上一致：超出单退化上限（6/6）、准确率空间超加性（+11.3，CI 排零）、新错误比例（41.5%）。三条都指向同一结论的独立证据。

关于 haze+cloud：s=5 的点估计为正（+1.62）但 CI 跨零（q=0.48），只能写作**趋势**，不能作为超加性的证据。但"超出最强单退化"在 s=5 上是 6/6（D=8.6 vs M=4.0），且新错误比例 22.9%——这两条说明它同样落在单退化解释之外，只是幅度小。

## 4. 对论文的影响

- E2 的表述从"组合退化存在超加性"改为 **"超加性在最高严重度出现，且不在低严重度出现"**，并明确这是阈值现象而非梯度现象（P1 失败）。
- 主图改为四点曲线 + 六条逐 run 折线，让读者直接看到 s=4→5 的跳变与 s≤4 的噪声。
- 论文必须写：P1 未成立，这是预注册失败的一次如实报告——它同时是"结论不是拟合出来的"的证据。

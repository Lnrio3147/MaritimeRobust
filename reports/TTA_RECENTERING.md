# 测试时重定心打不赢恒等——坐标平移路线关闭

2026-10-30。预注册 `PREREG_TTA_RECENTERING.md`（写于实现与评测前）。零训练、零微调，只改正推理路径。

## 2. 判据

| 编号 | 判据 | 结果 |
|---|---|---|
| T1 | R1 在 s=5 复合上 ≥ **+2.0 pp**，两种子，CI 排零 | **不成立**（−0.27，两种子异号） |
| T2 | clean \|Δ\| ≤ 1.0 pp | 勉强成立（−1.00 / −0.49） |
| T3 | R1 比 C1 高 ≥ 1.0 pp | 成立（C1 更差） |
| T4 | single 回退 ≤ 1.0 pp | 成立 |

按预注册 §4：T1 不成立 → **关闭测试时校正路线**，不再试分位数归一化、协方差白化、原型重估等变体。

## 3. 这说明什么

1. **漂移是真的，但不是病因。** 若复合退化只是把整片特征云同向平移，减去批次均值应当收回大部分损失。实测不仅没有收益，还略低于恒等。因此"云整体平移"这一诊断（M2 与弃权探针各自测到）是**现象的伴随物，不是原因**：类条件结构同时被破坏，把整体位置搬回去并不修复类间可分性。
2. **与另外两条阴性结果一致**：漂移加权训练（两个方向都失败）、漂移代理弃权（0/6 单元赢过熵）。三者从"用漂移做训练权重""用漂移做错误检测""用漂移做坐标校正"三个角度，指向同一结论——**逐图漂移只有诊断价值，没有可操作的干预价值**。
3. C1（logit 偏置）比 R1 更差，说明损失也不在输出层的公共偏置里。

## 4. 边界

- transductive：`μ_b` 需要一批同条件测试图（本实验 206 张），单图无法使用。即便有收益也不构成逐图部署方案；本实验连收益都没有。
- 单折（fold0）、两种子、单骨干（ConvNeXt-T）；按预注册未扩到其他折。
- 只测误差校正，不测错误检测（后者见 `SELECTIVE_PROBE.md`）。
